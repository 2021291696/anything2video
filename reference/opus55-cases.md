**路径**：Opus 5.5 案例库为只读外部资料库，不随本仓库分发——本机路径因环境而异（用环境变量或自行配置）；**库不在时按本文件时机表跳过对标，不阻塞流程**，**只读，别往里写东西**。

收录 1000+ 条用 Claude Opus 5.5「代码绘帧」做视频的公开案例（每条带技术路线、提示词原文或代码出处、证据分级）与逆向出的方法论。本 skill 与它同属代码绘帧路线，把它当**结构与审美的对标库**用。

## 边界

- **对标优先**：阶段 1 产出的对标片单是分镜骨架的**第一依据**——对标结论与配方默认骨架冲突时，以对标结论为准（借结构），并在分镜表注明改动与理由。
- **借结构与节奏，不借技术路线。** 库内六条路线（代码绘 2D / 讲解+TTS / 3D 实时 / 素材改造 / 外部视频模型管线 / 应用录屏）中，「素材改造」「外部管线」「应用录屏」与本 skill 硬性原则冲突（原创代码绘帧），只参考叙事与分镜；「代码绘 2D」「讲解+TTS」与 promo / explainer 配方同型，可深度对标。**例外（2026-10-02 拍板）**：人物形体例外条款生效后，「视频模型出人物+代码搭场景」的混合型（文章案例 4 型）可对标其合成、节奏与抠像手法，人物生成管线本身仍按 `recipes/custom.md` §12 纪律使用。
- 案例提示词是写给 Opus 5.5 的——**抄结构不抄措辞**，落到本 skill 一律走所选配方 + 硬性原则（原创、事实出处、品牌色纪律不因资料库放宽）。
- 案例视频本体不在库内（只有索引与原帖链接），要看片去出处。
- **缺失兜底**：库路径不存在或已失效时，跳过对标并在 `research/调研.md` 标注「无对标库」——流程照常走，不报错、不阻塞。
