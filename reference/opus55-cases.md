- **借结构与节奏，不借技术路线。** 库内六条路线（代码绘 2D / 讲解+TTS / 3D 实时 / 素材改造 / 外部视频模型管线 / 应用录屏）中，「素材改造」「外部管线」「应用录屏」与本 skill 硬性原则冲突（原创代码绘帧），只参考叙事与分镜；「代码绘 2D」「讲解+TTS」与 promo / explainer 配方同型，可深度对标。**例外（2026-10-02 拍板）**：人物形体例外条款生效后，「视频模型出人物+代码搭场景」的混合型（文章案例 4 型）可对标其合成、节奏与抠像手法，人物生成管线本身仍按 `recipes/custom.md` §12 纪律使用。**例外二（2026-10-03 拍板）**：AI 世界帧例外条款生效后，epic 配方对标「AI 世界底+代码信息层」混合型案例（OPUS 官方品牌片即此型）可深对标——其 AI 帧提示词结构、同章多帧一致性手法与伪影处理照 `reference/ai-frame-sop.md` 纪律执行；其余「素材改造」「外部管线」类仍只参考叙事与分镜。
