# 外部视频案例与证据分级

案例帮助研究叙事、构图、运动、材质、声音与制作流程。片子标题、作者自述、代码仓库和实际媒体分别能证明不同事项；候选帖子数量不能当作已经验证由某模型独立原创的视频数量，更不能推导本skill全面替代模型能力。

## 1. 可选案例库

工作区可能有 `awesome-opus-5-5-videos` 资料库；它是外部只读索引，不随skill分发，不是依赖。用户提供路径或检索到真实位置后使用，不把作者本机Windows路径写成安装前提。找不到时记录“未使用外部案例库”，按现有资料或公开来源继续。

| 资料 | 适用问题 |
|---|---|
| `README.zh-CN.md`、`data/cases.csv` | 找同类型候选案例、原帖和技术路线自述。 |
| `docs/prompt-playbook.zh-CN.md` | 比较先分镜后代码、确定性渲染与提示组织。 |
| `docs/methodology.zh-CN.md` | 研究多轮制作、工作分配和实际成本记录。 |
| `docs/prompt-matrix.zh-CN.md`、`docs/report.zh-CN.md` | 系统整理候选方法与边界。 |

文件名只是已知索引结构，先检查真实文件；文件不存在不编造其内容。媒体不在库内时查看原出处，未实际看过的条目不能写成“已分析运动与听感”。

## 2. 三种证据标签

| 标签 | 能证明什么 | 不能推导什么 |
|---|---|---|
| `author_claim` | 作者在可追溯原帖/文章里如何描述模型、时间、成本、流程。 | 未独立复测的模型归属、成本或官方背书。 |
| `verified_project` | 实际查看的源码、依赖、资产、命令、渲染媒体与本地测量。 | 仅凭代码就证明旁白听感、观众理解或每个原素材来源。 |
| `visual_inference` | 实际观看的具体片段呈现哪些视觉、节奏或合成特征。 | 画面“像AI”就确定模型、生成比例或技术管线。 |

一条案例可以同时有多个标签。研究记录URL、查看日期、媒体时间窗、观察、可借方法、不可证事项和许可；数值加测量条件。引用官方归属时另找真实官方出处，不能以文章题目含“官方”或品牌画面代替验证。

## 3. 借什么

先用受众、学习目标和真实内容判断参考是否相关。可借的信息包括开场问题如何建立、因果如何可视化、空间层次、动作承接、同章材质一致性、声音与结尾回扣。参考结论和配方样例冲突时记录调整理由；教学准确和项目契约优先。

代码图解、真实录屏、授权实录、生成场景等技术路线都可以研究。实际使用由本片镜头目的和素材许可决定；各配方允许按镜头混合，代码或可信实录承载精确文字、数字、UI与事实结果。AI路线按 `ai-frame-sop.md` 登记和验收，不凭“看起来像官方品牌片”给混合素材开免审例外。

参考媒体只供研究，不拿抽帧、片段或复制构图当本片原创资产。作者公开提示词不代表所有输入图、字体、声音、代码和成片可以任意再分发；实际采用前逐项核对许可。效果成功与否必须在本工程复验，不能抄一句提示词承诺相同模型质量。

## 5. 模板质感层的证据边界

模板含 `src/common/ShaderPost.tsx`，可提供颗粒、扫描线与暗角。历史项目曾记录确定性与性能验证；当前独立包未附同等渲染机器、媒体和完整测试数据，不能把历史“逐帧成本+0–30ms”当任何工程的保证。

使用前检查目标画幅、浏览器、参数和依赖，实渲连续片段；性能按同机同内容热渲比较，确定性按相同输入重复比较。深底、浅底、不同材质、文字清晰度和混合资产需各自验收。质感层不自动提升教学，水面折射等未实现效果不能在交付说明中声称已覆盖。
