# 跨片反同质化台账（style ledger）

**纪律（借自 guizang product video skill 的多片实践）**：同一工作区连续做片，按**维度分档**执行差异化——

- **风格锁定片（custom，风格即卖点）**：**锁死项不编**——材质/笔触/调色板/幕底/图元语言 = 风格本体（改动=破坏稳定性，须走 `styles/` 正本升级流程）；**必须变**的是开场手法、转场编排、运镜、叙事节奏、声音气质五项。
- **promo / explainer 片**：五项全变（色彩弧线本来就随主体品牌走）。

阶段 3 分镜前必读本表，本片的差异化声明写进分镜表「全局约束」（一句话：本片与《上一片》在哪些维度、差在哪）。表只记事实不做评价；新维度（如贯穿元素形态）自行加列。
