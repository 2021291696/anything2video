# 宣传视觉规范（promo 配方专用）

一句话：a2e 的 MG 底子不变（黑底、白描边 2–3px 黑填充图形、超粗黑体、紫色系光效），把「讲解节奏」换成「广告节奏」——**更大字、更快切、更少文字、品牌色纪律**。动效词汇与公式不重复造：**词汇表以 a2e `reference/explainer/motion-vocabulary.md` 为准**，本文只给 promo 的选择规则与数值；与该文档冲突时以它为准。

## 1. 排版

画布 1280×720@30fps。

### 1.1 大字层级（唯一层级表，镜头不得自创字号）

| 层级 | 字号 | 字体/字重 | 用途 | 附加 |
|---|---|---|---|---|
| L0 钩子 / CTA 主文 | 96–150px | Noto Sans SC 900（拉丁词用 Audiowide） | 钩子主标、CTA 端板动词 | 中文 scaleX .85；可 +1px 黑描边 paintOrder stroke；CTA 主文用品牌 primary 或白 |
| L1 卖点主标 | 64–96px | 同上 | 每卖点一屏主标（≤8 字） | 白字 + primary 硬投影（`BigNumber` 样式：`6px 6px 0` 主色 + 28px 同色柔光） |
| L2 小注 | 24–28px | Noto Sans SC 500–600 | 主标下一句注（≤20 字） | 灰 `#A0A0A1` 或白；**最小 24px**（比 explainer 图内说明的 22px 高一档——投放场景常在手机小窗看） |
| L3 品牌帽字 | 24–28px | Noto Sans SC 700 | 品牌帽的品牌名、联系方式 | letterSpacing 1 |
| 卡内标题 | 40–48px（缺省 44） | Noto Sans SC 900 | 卖点卡内的行内标题（屏级主标仍走 L0–L1） | 白字 scaleX 窄（组件缺省 0.86）；随卡排版不随屏 |
| 卡内小字 / 来源行 / 品牌条字 | 22–24px | Noto Sans SC 500–900 | 证明卡来源行、卖点卡小注、品牌条品牌名（900 白）与 slogan（500 灰） | **下限 22px**（本表唯一允许低于 L2 下限的一层：品牌条总高仅 33px、卡内来源行是元信息，24px 放不下/过重） |
| 数据字 | 72–110px | Orbitron 700 | 证明拍数字 | accent 色 + 同色发光（`GLOW_ORANGE` 同规格）；tabular-nums |

### 1.2 安全区与锚点

| 区域 | 像素 | 规则 |
|---|---|---|
| 内容区 | x60–1220，y110–660 | 所有大字、小注、演示图形只放这里。**本配方改为**：下界 y660（explainer 构建协议基线为 y620）——共存锚下小注底缘约 y638 按 660 合法、按 620 越界 |
| 顶部品牌帽 | y28–72，x60 起 | logo（高 28–32px）+ 品牌名 L3；钩子拍与 CTA 端板可整帽淡出 |
| 底部品牌条 | y687–720（常驻） | logo 小图（高 22px）+ 品牌名**左对齐**（logo 位 x28、品牌名 x60 起），slogan/CTA 短语**右对齐**（右缘留边 28px，与左端 logo 位对称）。**本配方改为**：本条自身常驻可读品牌文字（品牌名/slogan）——explainer 基线的 y687–720 仅允许背景/大图形穿过；除品牌条自身内容外，任何画面内容与入场轨迹仍不进这条 |
| 全屏锚 | 主标中心 (640,330) | 钩子、独立卖点屏、CTA 端板 |
| 共存锚 | 主标中心 (640,545) | 演示主体占上 2/3 时；小注在主标下方（主标字号 ×0.55 + 12）px |
| CTA 端板 | 全屏接管 ≥60 帧 | 品牌色底（primary 整屏，或黑底 + primary 大字）；CTA 主文居中 (640,330)，logo 居中 (640,180) 高 ≥40px；末尾淡出 ≥20 帧 |

### 1.3 关键词大字纪律
- 每屏**一套**「主标 + 小注」，不出现第二套文字层；换屏即换词。
- 换词动效：主标换词 GlitchIn（计入闪烁白名单），小注 SoftIn 8 帧淡入。
- 主标 ≤8 字、小注 ≤20 字，超预算删词，不缩字号、不折行（折行按缺陷）。
- 旁白逐句文本不上屏（与 explainer 字幕带的本质差异，见 `recipes/promo.md` §字幕策略）。

## 2. 节奏密度（每拍镜头时长上限）

| 拍 | 单镜头时长 | 上限 | 备注 |
|---|---|---|---|
| 钩子 | 60–90 帧 | **105 帧（3.5s）** | 超过 3.5s 钩子必拖；钩子内允许 2 镜（痛点 → 转机；**双镜时单镜下限放宽到 40 帧**，两镜合计 ≤105 帧） |
| 卖点 | 45–105 帧 | **120 帧（4s）** | 一卖点最多 2 镜（主标屏 + 演示屏）；每镜 ≥1 处可察觉变化 |
| 证明 | 60–120 帧 | 120 帧 | 数据 Counter 计数 14–26 帧；口碑引语卡最少停 75 帧 |
| CTA 端板 | ≥60 帧 | ≤150 帧 | <60 帧直接 QC fail（判据见 `recipes/promo.md` §7 第 3 条） |
| 任意镜头静止 | — | 同一构图无变化 ≤45 帧 | 到限加呼吸：柔光 30 帧周期 / 元素微移 / 一次 30 帧推近（规则同 a2e motion-vocabulary §节拍） |

- 转场帧预算：硬切为主；两镜之间过渡 ≤16 帧；全片甩出 whip ≤4 次、定点推近 ≤2 次。
- 密度基准：45–60s 档 10–14 镜 → 平均单镜 3.5–5s。低于 8 镜 = 拍数在灌水；高于 16 镜 = 在碎切，两边都要回分镜重排。

## 3. 转场词汇（出处声明）

词汇、公式与帧数**一律以 a2e `reference/explainer/motion-vocabulary.md` 为准**（其入场/强调/光效/离场/镜头运动/节拍/衔接/闪烁白名单各节全部适用）。本节只写 promo 的**选择规则**：

| promo 场景 | 用哪个词汇（a2e 名） | 要点 |
|---|---|---|
| 钩子主标入场 | **GlitchIn**（12 帧模板） | 白名单第 1 条；rgbSplit 变体可用 |
| 卖点切换 | 硬切（前镜末 6–8 帧归零淡出 + 后镜首帧 SoftIn）或**甩出 whip** | whip 全片 ≤4 次，只给卖点边界；衔接两侧写法沿用 a2e §衔接 |
| 演示元素出现 | 自下滑入（Δ≤120）/ 缩放入场 / 错峰 stagger(i,2) | 不用 GlitchIn 做错峰（像掉帧） |
| 证明数字 | **Counter 计数**（14–26 帧）+ 橙/accent 发光 | 落定帧白闪 3–6 帧 |
| CTA 收束 | **定点推近**（30–40 帧，s≤1.33）→ 端板接管 | 推近期间品牌帽/品牌条不动（屏幕空间） |
| 章节感 | **无**——promo 无章节卡、无进度条 | 进度感由品牌条承担（同屏常驻即锚定感） |

硬边界（与 a2e 同源，promo 下重申）：硬切前末帧必须归零（禁止 6.7%/帧 exitFade 单独用在硬切前）；每镜头 ≤1 处 GlitchIn；可见度 >20% 时不得结束 Sequence。

## 4. 品牌色纪律

- **色源唯一**：`template/src/recipes/promo.ts` 的主色 token（`accent` 及随主色推导的一组）；接品牌资产包 = 按解析规则替换这组 token（机制见 `reference/brand-assets.md` §3），无包时保持内置回退值（对照表 §4）。镜头源码**不得**出现 `ui.tsx`/`fx.tsx` 导出常量之外的彩色字面量；`ui.tsx` 的 PURPLE/ORANGE 等常量是经 `getActiveRecipe()` 从配方派生的别名，值自动随 token 走。
- **全片彩色 ≤3**：primary + accent + 至多一个强调色；黑白灰（`#FFF`/`#000`/灰阶）不计入。这是 `recipes/promo.md` §7 判据 4 的判据来源。
- 面积分配 60/30/10：黑/白底与灰 ≈60%；白描边图形与说明字 ≈30%；primary（大字/胶囊/端板）≤10%——**CTA 端板是唯一例外**，可整屏 primary；accent 只给一帧一个焦点（数字、按钮、对比中的「我方」）。
- 光效纪律（承 a2e motion-vocabulary §光效）：一帧内主角光 ≤1 处 + 重点光 ≤1 处；光只有 primary / accent / 警示红三色；白 bloom 只给结构线条。
- glitch 的 RGB 错位色（品红/青）不计入 3 色，但只随白名单 GlitchIn 出现。
