# 宣传视觉规范（promo 配方）

产品宣传的画面要让观众看到具体困境、操作和结果。先按 `recipes/promo.md` 定内容，再选择视觉系统；模板中的黑底、描边、发光与大字是一种现成皮肤，不是所有宣传片的默认审美。工程、素材和交付遵循 `production-contract.md`，镜头决策见 `directing-playbook.md`。

## 1. 排版起步值

下表是 **1280×720 横屏样例**，用于初稿比较，不是其他画幅的尺寸门禁。原生竖屏应按项目 width/height、安全区和手机实看片重新排版，不能直接把本表坐标放大。

| 层级 | 横屏起步字号 | 用途与调整条件 |
|---|---|---|
| 钩子 / CTA 主文 | 72–120px | 一个具体问题或动作；字体、字数和留白决定终值。 |
| 卖点主标 | 56–88px | 对准真实操作或结果，不遮住演示对象。 |
| 操作标签 / 小注 | 28–36px | 能在观看距离读清；命令可分步骤、换行。 |
| 来源 / 条件 | 24–30px | 证明数字的单位、范围和出处；空间不足先改构图。 |
| 品牌名称 | 28–40px | 只在需要识别品牌的镜头出现。 |
| 结果数字 | 64–104px | 单位、来源和比较条件同屏可核查。 |

中文用已授权且包含相应字形的字体；拉丁字体不能代替 CJK 字库。字重、描边、字距、阴影与发光均按皮肤选用，正文优先清晰。不要用机械压窄或缩字解决超量内容。

### 安全区与位置

先在项目设计稿定义内容区、字幕区和平台覆盖区，再定位主体。横屏可从四周约5%的留白起步；平台UI和真实阅读测试决定最终边界。抖音竖屏保守制作区见统一契约，不能当作平台固定尺寸。

品牌帽、品牌条和端板是可选工具。启用时按画幅调整位置，检查与字幕、控件、演示步骤的遮挡；持续品牌条不能挤占教学主体。结尾地址、命令、二维码需要独立阅读停留，默认2–4秒可作首轮样音起步值，实际读完与扫码成功才是证据。

### 文案与屏幕关系

每屏一个主焦点，文字、动作和高亮共同解释它。主标约8字、小注约20字可作为初稿预算；超量时改句、拆步骤或合理换行，保留语义并实测，不以“不折行”为硬门。事实条件不能为了大字效果省略。

旁白字幕按受众和平台选择。启用时字幕解释目的、操作标签对准对象，避免多个层复述同一句。是否关闭旁白字幕与模板设置必须一致。

## 2. 节奏从任务决定

| 拍 | 起步时长 | 需要保留的时间 |
|---|---|---|
| 困境 / 钩子 | 2–3秒 | 观众识别对象与反差。 |
| 功能演示 | 3–7秒或更长 | 完整输入、操作、反馈；不能按固定秒数截断步骤。 |
| 结果 / 证明 | 3–6秒 | 看清终值、单位、条件与原始结果。 |
| CTA | 2–4秒 | 读完并知道下一步。 |

这些是样例预算。镜头数取决于信息与操作，不能按“每分钟必须几镜”替代分镜。有意静止可以用于阅读、比较、等待反馈、看清结果；分镜写明原因和留白窗口。需要新信息时改变对象状态或调整稿件，不靠无意义呼吸、粒子或抖动延长镜头。

## 3. 转场与动作选择

可用实现词汇见包内 `explainer/motion-vocabulary.md`；其中旧样片的颜色、固定帧数、效果配额与常亮要求是风格参考，不能覆盖本文件和统一契约。导演层原则见 `motion-language.md`。

| 场景 | 候选表现 | 验证重点 |
|---|---|---|
| 痛点转为操作 | 同一对象改状态、硬切或局部显现 | 前后对象身份和问题连续。 |
| 操作分步 | 选择、展开、指示线、错峰 | 真实因果顺序；同步步骤可以同步。 |
| 结果到证据 | 同尺度比较、数字落定、原始输出 | 最终值可读，中间计数不是新事实。 |
| 镜头承接 | 共享对象、匹配切、连续位置 | 边界无非预期空白、闪帧或对象跳变。 |
| 结尾收束 | 贯穿对象完成动作、CTA清晰出现 | 收口能回答开场问题。 |

Glitch、白闪、甩出、推拉和辉光都按意图选择，零次使用可成立。Glitch与闪烁若启用，应登记时间窗，查看真实连续片段并控制刺激；指示标签和长命令通常采用稳定显现。硬切可以直接接完整画面，淡出只有选择它时才需准确收尾；不强制每次硬切先黑场。相机只动需要重构的内容，HUD和字幕保持屏幕空间可读。

## 4. 品牌与色彩

品牌解析见 `brand-assets.md`。保留用户已提供的有效品牌名、颜色和资产；没有品牌体系时，用中性底与有语义的强调色起稿，内置palette只是候选。代码信息层使用共享token，避免跨镜头语义漂移。

设计稿声明颜色用途：品牌识别、可操作对象、对比、警示或结果。大面积强调色、多个高亮和强光需服务焦点；没有固定三色数、60/30/10面积配额，也不为配额误判照片、实录和生成素材。警示/成功等语义色可以有明确用途；颜色不能独自承担关键区别。

需要材质光照时记录主光、阴影与环境关系；纯平图解无需制造受光面。实际数字、UI和文字的对比度优先。肤色、产品色和原始图像色不应为了统一品牌色被任意染色。

## 5. 验证范围

先渲开场、复杂中段、结尾的真实运动片段，检查焦点、操作链、可读性、品牌识别、动作落点和声音。样张只能证明静态风格；连续片段和整片审查才能提供运动、节奏与教学证据。记录检查范围和 `passed/failed/not_performed`，具体效果数量不能替代审片结论。
