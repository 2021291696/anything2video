## 1. 完整运动链（一个重动作的七段）

**预备 → 加速/拉伸 → 冲击 → 压扁 → 过冲 → 回稳 → 次级响应**

| 段 | 是什么 | 落到本 skill |
|---|---|---|
| 预备 | 动作前的反向蓄力（落前先微升、出拳先回收） | 主体高光动作前 3–6 帧反向小位移/微缩；**预备缺失是「匀速滑动感」的第一根源** |
| 加速/拉伸 | 沿运动轴拉长（速度峰值附近） | 挤压拉伸条款见 §3；scale 1.1–1.25、反向 1/该值（体积守恒），只给峰值 ±2–4 帧 |
| 冲击 | 接触帧 | 冲击帧=节拍帧；震屏/白闪只在这里（白名单管辖不变） |
| 压扁 | 沿冲击轴压短 | 同拉伸反向；冲击后 2–3 帧，幅度 ≤20% |
| 过冲 | 冲过目标再收回 | Remotion `spring()` 天然带；只在能量说得通处用（重物落地、卡片贴入），轻量文本不用 |
| 回稳 | 余震收敛到静帧 | 2–4 帧幂缓出；回稳后进 idle 微动（lessons 09-30 端板条款），禁冻死 |
| 次级响应 | 环境与配角对主事件的反应 | §2 错相阶梯的末端两档（阴影/文字/SFX） |

原则三条：**先有原因再有形变**（压扁/拉伸来自速度与冲量，不是随机 easing）；**动量连续**（上一动作末速度=下一状态初值，分段函数端点一阶连续或显式衰减衔接，禁每段从 0 重新弹出——叠加弹簧换目标合法）；**不是每个动作都要七段全走**（轻量元素三段够：入场→持稳→离场，但主体的高光动作必须有预备与回稳）。

## 2. 错相阶梯（层次感的时间维）

**主体先动 → 次层滞后 2–4 帧 → 相机再晚 2–3 帧 → 阴影/倒影更晚 → 文字/SFX 最后。**

- 同一时刻尽量一个主事件（promo §9「每屏唯一主角」的时间维版本——主角条款管空间焦点，本条管时间焦点）。
- 多主体协奏 = 同一节奏、不同相位：发起 → 回应 → 截断 → 接管；各元素自有函数规则，整体汇成一个总规律（例：列表项按 2 帧错峰入场后，各自以微小相位差呼吸，而不是同频同相）。
- **翻车信号 = 所有层共用一条时间函数**：全体同步淡入、整幅同步位移 = PPT 同步感。既有协议已禁「错峰用 GlitchIn」（像掉帧），本条补相位维：即使全用 SoftIn，也按阶梯错开。
- 相机（CameraRig）滞后于主体 2–3 帧起步是合法手法；运镜与错峰互斥的既有红线不变（orchestration §3.1）。

## 3. 物理效果 checklist（分镜按镜头任务选配，进派单任务书）

| 效果 | 什么时候用 | 画法要点（30fps 帧数档） |
|---|---|---|
| 重力抛物线 | 掉落/投掷 | y 二次曲线+水平匀速；落点=冲击帧；起点给 2–4 帧预备反向 |
| 碰撞与连锁 | 多物体传动 | 接触帧逐级对齐，每级延迟 2–4 帧（=§2 阶梯） |
| 弹跳 | 落地反弹 | 反弹高度衰减 ≈60%/次，2–3 次收；每次触地压扁 §1 |
| 滚动与惯性 | 球/轮/滑出 | 表面接触点线速度一致；停止前惯性滑行 3–6 帧衰减 |
| 挤压拉伸 | 加速/冲击 | 沿运动轴 1.1–1.25，反向 1/该值；只给速度峰值 ±2–4 帧，静止期恒 1 |
| 弹簧回弹 | 到达目标 | `spring()` 缺省；过冲量调 damping，禁叠加到发散 |
| 软体形变 | 有机主体 | 控制点偏移跟随速度方向；形变量∝速度，禁随机抖动 |
| 弯曲/折叠/扭转 | 纸/布/线类柔性物 | 受力端先弯、固定端后弯（传播延迟 1–2 帧/段） |
| 水波/旋涡 | 液面/能量场 | 正弦叠加、相位随半径偏移；波纹扩散速度恒定 |
| 漂浮粒子 | 氛围/聚散 | 优先用既有图元（粒子池/星点/粉尘）；粒子是点缀不是主角（每屏唯一主角纪律） |

总原则：**受力起点明确**——接触、形变、后续运动连贯发生；没有受力依据的形变一律删。

## 4. 光照纪律（三条款，§全局约束新增「主光方向声明」的判据来源）

1. **主光方向整片统一**：分镜表全局约束写一行声明（如「主光左上 45°，冷白」）；高光边、投影方向、渐变朝向全片照此执行。CTA 端板/压黑段可例外，例外写进声明。QC 抽帧核对：同一物体的亮面方向前后镜头矛盾记低。
2. **静物不死**：位置不动的元素，高光、受光面、倒影仍随时间微动——实现即 lessons 09-30 的 idle 微动（氛围光慢脉动 + 辉光呼吸）；「关键物体冻死」（位置静止且高光全静态 >45 帧）记低。
3. **冲击传导分层**：冲击传到环境（震屏/波纹/尘屑）按 §2 阶梯分层错相，禁整幅一起抖。震屏只给白名单冲击帧 ±2 帧，幅度 ≤2px（像素风格片 1–2px，其它配方 ≤3px、≤6 帧）；HUD/字幕带照旧不动（orchestration §3.1 红线优先）。

## 5. 声音从运动长出（与既有音效轨条款接合）

- 选型按动作物理：速度 → whoosh；冲量 → impact；出现 → pop/ding；计数落定 → ding+白闪（既有约定不变）。分镜表「音效事件表」**先写运动再写声音**（「卡片拍入桌面@f210 → impact」）。
- **微偏移**（卡点≠全员同帧）：预备音略早（−2…0 帧）、撞击正拍（0…+2）、碎屑/余响略后（+3…+8）。全层卡同一帧反而假。
- 落点计算仍走 `sfx_landmarks.py` 实测 onset/peak（cue.at = 动作帧÷30 − onset，既有公式不变）。

## 6. 拍点网格前置（BGM 卡点驱动分镜）

**流程位置：阶段 2 选定 BGM 后、阶段 3 分镜前**，主脚本跑：

```bash
python3 scripts/beat_grid.py public/assets/<slug>/bgm.wav --out script/beat_grid.json
```

产出 BPM、拍点/重拍秒表与帧表（`--fps 30` 缺省）。使用规则：

- **可靠性门（先看这个）**：`beat_grid.json` 的 `reliable` 为 `false`（BPM 置信度 <3.0，Tapis 类极简垫乐/ambient 曲常见）＝此曲无清晰拍点——节拍列按既有口径（字幕块起始帧 −6…+3）排、不声明卡拍，BGM 照常垫底，QC 重拍核对自然不触发（只查「分镜声明卡拍」的镜头）；以下各条仅在 `reliable: true` 时适用。
- **重动作对重拍**：分镜表「节拍」列在重拍 ±3 帧内取值；次要动作不强行卡拍——**不是每拍都要动**。
- 微偏移同 §5：卡点不等于全员同帧。
- 双曲结构的换曲点优先落在重拍或压黑段（bgm-library §使用约定 1 的细化）。
- 程序编曲（score_gen）的 BPM 在参数里已知（cinematic 100 / light 112 / lofi 88），直接引用不重测；静音片跳过本节。
- 判据接线：QC §4.1 判据 2 照旧；新增——有 BGM 且分镜声明卡拍的镜头，关键元素出现帧与 `beat_grid.json` 重拍偏差 >6 帧记低。

## 7. 缺省禁止清单（分镜表全局约束必抄；配方可显式覆盖，覆盖须写明）

| 禁止 | 为什么 | 既有判据对应 |
|---|---|---|
| 居中大字 + 渐变底的默认构图 | 模型无约束时的默认风格，同质化元凶 | promo 大字层级 + §9 色彩弧线管着；explainer/custom 同禁「无设计理由的居中大字+渐变底」 |
| 所有元素同时淡入 | 错相阶梯为零 | §2；QC 判据 6 补充立案 |
| 匀速大位移 | 无预备无回稳的滑行感 | §1；QC 判据 6「线性大位移」已有 |
| 整幅推拉 / 整幅抖动 | 相机与内容层不分离 | §4.3；运镜协议已有 |
| 死轮廓位移 | 主体动、高光阴影不动 | §4.2 |
| 空拍（长静止无新信息） | 节奏死水 | promo 节奏密度表 45 帧上限已有，此处原则重申 |
| 满屏小字 | 无焦点 | 每屏唯一主角 + 最小字号已有 |

覆盖备注：本表是**缺省集**，配方/设计卡显式覆盖合法（如 swiss 纯平配方禁 idle 动画即对 §4.2 的显式覆盖），覆盖声明写进分镜表全局约束。
