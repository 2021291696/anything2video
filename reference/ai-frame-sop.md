# AI素材生成与合成SOP

所有配方均可按镜头启用AI场景、材质或人物素材。需要先证明它对镜头有作用，并保持精确信息可控制；工程、许可与披露要求见 `production-contract.md`。生成通道和宿主多模态能力分开测试，不根据产品名字假定可生成图像、输入MP4或听音频。

## 1. 分工

| 适合素材生成 | 精确信息由代码或实录负责 |
|---|---|
| 有机材质、非精确世界、复杂人体、场景氛围 | 字幕、标题、数字、年份、命令、数据结果、精确UI |
| 需要自然运动的火、水、烟、风或动作 | 因果图示、流程、家谱关系、真实产品行为 |
| 有叙事作用的非事实性意象 | 品牌标志、必要符号、需要读出的铭文 |

按镜头决定素材位置和职责。历史主题的生成场景是示意，不作为考古、人物或年代的事实证据。教程优先展示实际机制和输出，不能用历史器物或人物表情填补未实现的演示。

## 2. 提示词与候选

先写镜头目的、主体动作、构图、光源、媒介、目标画幅、信息安全区、连续性条件和负向约束，再生成。通用起步模板：

```text
用途：<镜头ID与目的，世界/材质/人物层>。
主体与动作：<单一主要对象、起始状态、动作、结果>。
构图：<景别、机位、焦点、实际宽高比、预留信息区域>。
视觉：<媒介与材质、主光方向、色温、背景>。
连续性：<参考输入、需保持的身份/器物/空间关系>。
画面不生成标题、字幕、数字、标识或伪铭文；精确信息后期合成。
```

场景确需真实文字时使用授权原件或代码补字，不能将随机生成字形称为资料。视频提示增加机位与动作时长，视频生成结果的实际fps、时长和裁切要测量。

首轮用少量候选比较一个关键不确定因素，通常2–3个即可，但候选数不是质量硬门。看全尺寸、实际裁切和信息层合成样片后再扩建；不能只审未合成的小缩略图。

## 3. 一致性

同prompt、同seed和同模型设置可以控制部分变量，**不能保证同一人物、空间、光线或相同像素结果**。优先可用的参考图/角色约束/姿态控制，记录实际支持程度，逐镜对照身份、器物、方向、光和背景关系。

跨章色温差可以是设计，章内不希望的漂移需修复；从定稿素材提取palette帮助代码层兼容。参考输入必须有来源与使用权，不能把参考成片抽帧当原创世界底或绕开许可。

最终确定性来自选定媒体文件的完整sha256、固定裁切与代码参数，不来自“以后还能用同seed再生成”。保存已选原件及实际响应信息；别将平台返回缺失的seed自行补编。

## 4. 伪影与合成检查

每条素材先看全尺寸，再看主体与风险区放大；视频查看连续片段并抽动作/组界关键帧。放大2倍是起步方法，不能由一帧推出整段通过。

| 检查 | 具体风险 |
|---|---|
| 文字与铭文 | 乱字、假标识、伪刻字、水印；与后期精确信息混淆。 |
| 结构与身份 | 多指、融体、透视矛盾、器物变形、身份/服饰漂移、镜像与左右错误。 |
| 连续运动 | 人物消失、物体穿透、动作回跳、边缘闪烁、纹理爬动、帧间变形。 |
| 合成 | 抠像绿溢、发丝切断、接触影缺失、主光/机位冲突、裁切丢动作、字幕遮挡。 |
| 信息与伦理来源 | 生成画面冒充实拍或数据证据、未经授权的人物身份、无许可参考输入。 |

命中缺陷先定位原因，再重生成、改约束、换机位、局部修补或重构镜头。裁切避让只在不损失镜头任务且最终样片再次通过时成立；不能拿遮住缺陷当完整结构修复。

## 5. 登记

素材清单和结构化storyboard逐条登记；实际许可单独核查，不将API条款写成“免版权”。

| 字段 | 必须记录 |
|---|---|
| path / sha256 | 工程内真实文件、完整64位sha256；文件变更同步更新。 |
| source / license | 生成服务/用户资料/原始URL；实际许可条款、取得日期与必要署名。 |
| usage | 所属镜头与帧窗、素材承担的功能、裁切/合成方式。 |
| model / version | 实际模型与可获得的版本信息；未知版本如实记未提供。 |
| prompt | 发送的完整prompt及负向条件，不能只记“史诗风格”。 |
| seed / reference | 实际seed或n/a；所有参考输入的路径、来源与许可。 |
| qc | 实际查看范围、工具、发现与passed/failed/not_performed；生成器pending不等于通过。 |
| disclosure | 交付说明中的AI素材标注及目标平台适用声明安排。 |

格式必须兼容当前 `check-plan.mjs` 的字段合同。人工报告不得把缺检查能力填passed；schema所需qc字段存在也不能代替真实审核。用户授权发布成片时按当期平台界面启用适用AI声明，片内小字不能替代发布按钮。

模板 `gen_world_frames.py` 用 project.json 的 slug 与画幅组织候选；material 必须显式，生成按 take 区分且默认保护已有文件。MANIFEST.json 保存完整 SHA256、实际提交 prompt 与负向词，qc.textFree/geometry/continuity 默认 not_performed。实际服务尺寸、源图像与裁切仍需核对。手工 --register 要给 source/license/model/prompt/seed/disclosure；真实许可和三查通过后纳入 storyboard.assets，不自动认证。

## 6. 轮次与质量

没有统一的“两轮后自动降级”。依据具体缺陷逐轮优化并保留候选、参数与对比证据；每轮应改变与问题相关的因素，避免随机重试。用户已允许充足预算时继续修复，必要时重构构图、换适合的生成能力或改用质量更好的授权资产。

素材路线变化必须保持原镜头的信息和质量目标，并重新验收。无法达到要求时保留工程和明确未完成项，不能为了结束任务自动交更短、抽象化或低质量版本。能力与外部状态确实阻塞时如实说明，同时继续可独立推进的工程工作。

静帧、视频、程序质感不是高低级排名。选择依据是动作真实性、信息任务、风格兼容、可修复性与最终效果；静帧推镜头撑不住的动作换实际动态方案，有意静止的阅读镜头不因探针低活性被强行加运动。
