# AI 帧生成 SOP（AI 世界帧例外条款执行细则，epic 配方专属）

> 条款出处：SKILL.md 硬性原则 1 例外③（2026-10-03 拍板）。本文件是该条款的执行细则：分工判据、提示词模板、一致性手法、伪影三查、MANIFEST 字段。配方侧入口 `recipes/epic.md` §5；生成走主控侧当期可用的图像生成通道（用哪个模型登记进 MANIFEST，不绑死工具）。

## 1. 分工判据表（一行一条，分歧时从严）

| 给 AI（世界底） | 必须代码（信息层） |
|---|---|
| 照片级场景/材质/氛围：岩壁、深海、织机、雪夜、棋盘、居室 | 一切文字（标题/字幕/角标/日期） |
| 纹理级有机运动：火焰摆动、水面波光、落雪落花、烟尘（≤4s 短片段） | 数字与编号（年份数轴、计数、帧标） |
| 光影氛围底（烛光/体积光/暗角内的环境） | 铭文与刻字（齿轮齿圈、印章、碑文——AI 必出伪铭文，OPUS 实锤 ΔIKAIOΛA） |
| 非精确的背景陈设（书架/器物群/远景） | 图示与图解（家谱树、注意力弧线、迷宫路径、像素花） |
| 构图主体唯一、无信息意图的画面 | 贯穿符号的精确形态（品牌符号不许 AI 随机演绎——代码画，或 AI 出底后代码覆写符号） |

一句话：**AI 出世界，代码出秩序**（`reference/epic-brand-film.md` 要素 5）。画面需要"被读出信息"的部分一律代码。

## 2. 世界帧提示词模板（四要素 + 参数槽；槽位填实、措辞不锁死）

```
[媒介] 风格的 [场景]，
单一主体：[主体描述]，
光源：[方向 + 质感（如 画左低位暖光、柔和体积光）]，
画幅与质感：16:9，[材质语言（如 赭石颜料岩面 / 深海水下悬浮颗粒 / 浮世绘木刻套色）]，
画面中不出现任何文字、字母、数字、符号或刻字。
```

- **四要素**：媒介风格（决定色温与材质语言，与分镜表该章条目一致）/ 单一主体（一画一世界，多主体=章内拥挤）/ 光源方向（写进分镜表「主光方向声明」，代码侧高光对齐它）/ 负向禁字（最后一句固定保留——这是防乱字的第一道闸，删它=违约）。
- **参数槽纪律**：方括号槽位按章填实；模板措辞可换，四要素结构与负向禁字不可省。
- 每章产出 **2–3 张候选**（首章确认点⑤给用户选；后续章按首章定稿的风格基准批量生成，主脚本自审三查后择优，不再逐章打断用户）。

## 3. 一致性三招（跨章不散的底线）

1. **同章多帧**：同章补拍/换角度用同一提示词 + 同 seed（模型支持时）或首帧参考图（图生图），保证同章同世界。
2. **跨章色温锚**：每章提示词的媒介风格从分镜表「色彩弧线」取值（epic.md §2）——章与章的色温差是设计（色彩即转场），章内不得漂移。生成定稿后从定稿帧取 3–4 色回写分镜表该章色板。
3. **材质词汇表**：全片共用一份材质语言清单（岩面/水下/绢本/木刻/纸纹…），逐章指定；禁止每章即兴发明新材质词——词汇表放分镜表全局约束。

## 4. 伪影三查（QC 硬门，与 `recipes/epic.md` §7 判据 5 同源）

每张入册帧放大 2× 目检，命中任一 = 重生成或 crop 避让，不得带伤交付：

| 查 | 特征 | 处置 |
|---|---|---|
| ① 乱字 | 画面内任何疑似文字/字母/数字的纹理（招牌、纸面、布纹上尤甚） | 负向禁字重申重生成；或 crop 避让 + 代码层补正确文字 |
| ② 伪铭文 | 器物上似是而非的刻字/铭文（齿轮齿圈、印章、石碑高发） | 同上；结构性器物优先改代码绘制（分工判据表第 4 行） |
| ③ 形态崩坏 | 多指/融体/肢体矛盾/透视塌陷/镜像文字 | 重生成；连续 3 次仍崩 = 换构图简化主体，不硬凑 |

## 5. MANIFEST 字段（epic 扩表，逐条登记）

在既有四字段（sha256 / 来源 URL / 许可 / 用途）之上，AI 帧逐条追加：

| 字段 | 说明 |
|---|---|
| model / version | 生成模型与版本号 |
| prompt | 提示词全文（含负向禁字句） |
| seed / ref | seed 值或参考图来源（可复现性；不支持则记 "n/a"） |
| chapter / take | 所属章与候选轮次（首章样张 t1-t3、批量 t1） |
| qc | 三查结论（pass / 重生成轮数 / crop 避让说明） |

交付说明「AI 生成素材清单」节逐条照抄此表（SKILL.md 例外③的强制披露口径）；登记缺失 = QC 判据 8 fail。

## 6. 成本与轮次纪律

- 首章样张（确认点⑤）→ 用户定稿 → 其余章批量生成，**全片批量最多两轮**：第三轮仍不合格的章，降级方案 = 该章世界底改代码绘制（抽象化/剪影化处理）或换免版权 B-roll——不许无限重生成烧预算。
- 单章短片段（纹理级运动）只在该章"静帧推镜头撑不住"时启用，全片 ≤4 段（OPUS 全片 177s 也只有火焰/水面/落雪/花瓣四处）——能 Ken Burns 的不生成视频。
