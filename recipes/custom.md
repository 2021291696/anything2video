# custom — 自定义视觉风格配方（沙画/剪纸/水墨等风格即卖点的片子）

**定位一句话**：提示词指定具象视觉风格、且风格本身就是成片卖点的片子走本配方——与 promo/explainer 同规格的生产纪律，但视觉体系每片新建（图纸先行）。常规宣传片/讲解片不用本配方（回 `promo.md` / `explainer.md`）。

> **接线说明（对本配方契约 §0 的例外）**：本配方**不注册** `config.recipe` 新枚举——工程内 `recipe` 保持基础配方取值（通常 `'promo'`，以避开 explainer 覆盖层），风格完全由项目级图元库（如 `src/sand.tsx`/`src/ink.tsx`）接管；选型经 SKILL.md 路由表进入本文件，而非经 `config.recipe`。

> **已验证参考实现**：`usa250-sand`（灯箱沙画工程，本机路径不随仓库分发；132.7s 英文版 + 119.9s 中文版，frame_metrics 高 0/中 0/低 0）。本配方所有数字与图元清单都以它为实证；风格不同的片子继承的是**流程与硬杠**，不是沙画的具体色值。

## 1. 图纸先行（本配方第一硬杠，也是与其它配方的根本差异）
新视觉体系 = 一套不存在的图元语言，**图纸未定不派工**：
1. 主脚本先建风格图元库（如沙画的 `src/sand.tsx`：底/铺层/勾线/体渲染/手影/颗粒/转场，含明暗双变体）+ 纹理资产生成脚本，`npx tsc --noEmit` 过审；
2. 渲 1–2 帧**风格样张**给用户确认（新增确认点⑤，见 §确认点差异）；
3. 图纸过审后才允许按 `reference/workflow-orchestration.md` 阶段 5b 并行派工——建组任务书必须内嵌图元库清单与质量硬杠，禁止 agent 自造图元。

## 1.5 同风格复用（库资产化，第二部片起）
**已验证风格（`styles/` 下有正本的：sand/chalk/blueprint/neon）的第二部片从拷库开工，不走图纸先行全流程**：
1. 从 `styles/<风格>/` 拷图元库 + 纹理进新项目（`src/` 与 `public/assets/<slug>/`），按 SPEC「复用适配点」改 `staticFile` slug；
2. **开工样张回归**：渲 2 帧 vs 正本 `sample.jpg` 并排三查——色板 token / 笔触质感 / 版式锚点，漂移=缺陷；
3. 建组任务书内嵌 SPEC 锁死项（调色板/笔触参数/版式/禁忌），QC 按该风格豁免档执行。
图元库升级 = 正本升级：改 `styles/` 文件 + SPEC 同步 + style-ledger 记行；项目内临时改动不回写，除非验证过。新风格首部片仍走 §1 全流程，收线后按 `styles/README.md` 入库。

## 2. 叙事骨架与 beats
继承所选基础配方的骨架（沙画叙事片 = 幕结构：每章一幕、幕内「铺沙→作画→抹沙」三段式）。本配方只管"怎么画"，骨架/拍表照抄基础配方。

## 3. 视觉 token
- **配色来源**：风格自带调色板（沙画 = 纸底/深沙/亮沙/琥珀四级），写进图纸库常量；品牌包按 `reference/brand-assets.md` 解析后替换强调色 token。
- **图标骨架铁律（辨识度死穴，lessons 实锤）**：具象形体（建筑/器物/动物/载具）**禁止模型盲画 path**——盲画的贝塞尔曲线一眼假且无法迭代。改用 Iconify 开源骨架（MIT/Apache 优先，CC-BY 须在交付 MANIFEST 署名）+ 两阶段渲染：勾线画入（沙画师勾轮廓）→ 铺沙填色 + 形内颗粒（铺沙成形）。参考组件 `SandIcon`（usa250 `src/sand.tsx`）与骨架库 `src/icons.ts`。
- **性能杠**：禁元素级逐帧漂移纹理（clipPath+image 每帧重光栅化 = 塌方源）；质感由**全局颗粒层**统一出。单帧渲染 ≤600ms（探针 500ms 塌方线留余量）。
- **画面文字语言** = 旁白语言，逐字表写在建组任务书。
- **离场窗协议（与 `reference/workflow-orchestration.md` §3.1 对齐）**：默认离场 = 幂缓入 + 每帧 6.7% 淡出至归零；声明式偏离可登记 6–12f 离场窗（登记进 BUILD_NOTES），但不得压高光持稳段（chalk 蒙太奇先例）。

## 4. 时长档
继承基础配方档位。双语片的旁白语言可换：中文 ≈4.5–5 字/秒，英文≈等价信息量 ×1.25 时长；成片时长差 >15% 加/删句，不靠改语速凑。**换语言 = 时间轴全变 = 八幕帧号必须重排**（F0/END 常量 + 组表 + BG 范围三处同步）。

## 5. 字幕策略
`config.subs` 三态：`'none'`（默认，风格化画面通常无字幕带）｜`'cn'`｜`'bilingual'`。双语 = `BilingualLine`：主行（旁白语言）40px @y622 + 对照行 23px @y668；对照行写在解说词 `@EN:`/`@CN:` 行，由 tts_build 进 subs.ts。无进度条的视觉注意 y668 以下留空。

## 6. 素材策略
- 代码绘制为默认；**开源图标骨架**视同字体内使用（MIT/Apache/CC-BY），逐条登记交付说明 MANIFEST（图标名/来源 URL/许可/用途）。
- AI 生图素材默认**不用**（与硬性原则①冲突，需用户明确拍板修改原则后方可引入）。
- 禁止项：实拍帧、未登记来源的任何素材。

## 7. 音频策略（三层混音，`scripts/mix_audio.py` 已入模板）
- 旁白：**默认云端 TTS（见 `reference/workflow-orchestration.md` §7，中文/英文都支持）**；无云端通道时回退 `tts_build.py`（edge-tts 默认 `zh-CN-YunxiNeural` +8%、英文 kokoro `am_liam`，`TTS_ENGINE=auto` 按解说词语言自动选）。**先渲 3–4 个候选样音给用户挑**，音色是用户主观题。
- BGM：免版权来源（Incompetech/Pixabay 等），登记曲目/作者/许可/URL；混音前 **RMS 归一 ≈0.055**（约为旁白响度一半的可闻床——固定小增益等于"混了但听不见"，lessons 实锤），2s 淡入 4s 淡出。
- 音效：numpy 程序合成（噪声整形：铺沙=双重低通缓包络、扫掠=带通气流）或免版权音效库；每章起点/收尾各一处为上限。

## 8. QC 判据（继承基础配方全部探针，另加三条）
| 判据 | 阈值 | 核对方法 |
|---|---|---|
| 辨识度 | 具象形体抽帧给未参与者看 ≤3 秒能说出是什么 | 每幕主体帧抽 1 张，问一圈 |
| 性能塌方 | probe_frame_cost 无 >500ms 帧 | 阶段 6 强制门（existing） |
| 双语对位 | 字幕主行=旁白语言；对照行与句子同起止 | 抽 2 帧/章核对 subs.ts |

## 9. 确认点差异
| 基准 | 差异 |
|---|---|
| ① 时长与语言 | 改问法：「语言与字幕：中文／英文／中文旁白+中英双语字幕？」——语言决定 TTS、画面文字与时间轴，字幕模式决定 subs 渲染 |
| ② 解说词定稿 | 保留；双语片定稿时**同时交对照语言译文**（逐句，不是概译） |
| ③ TTS 偏好 | 改为**样音制**：渲 3–4 个候选音色各 10 秒样音给用户挑（音色是主观题，不代选） |
| ④ 打样 | 保留（前 5 秒/30 秒按基础配方） |
| ⑤（新增）风格样张 | 图纸完成后渲 1–2 帧给用户确认风格方向，过了才并行派工——图纸返工成本随派工数放大 |

## 10. 工作流差异（对 SKILL.md 流程的两处改写）
1. 阶段 4（覆盖层与图元）扩展为「图纸先行」：主脚本建风格图元库 + 纹理资产 + 风格样张确认；
2. 阶段 6 后加「三层混音」：`mix_audio.py`（旁白备份 → BGM RMS 归一 → 音效 → 软限幅），渲前完成。重跑 `tts_build.py` 后的旁白正本新鲜性由 `mix_audio.py` 自动守卫（audio.wav 更新即自动重备份 `audio_narration.wav`）；手工 inline 混音路线仍需先删旧 `audio_narration.wav` 再混。
