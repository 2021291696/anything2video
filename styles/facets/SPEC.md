# SPEC：分析立体主义（facets）

**正本源工程**：`samples-v4/facets`（2026-10-07 验证交付）｜**图元库**：工程 `src/style/`（types.ts 锁死 token+帧锚点 + rand.ts 种子随机/缓动/混色 + plane.ts 透明叠面空间/plane/wood/segs + facetize.ts 切面器/离屏层纪律/散落包络 + figure.ts 双视角脸/毕加索结构 + props.ts 窗四格/模版字/报纸/吉他 + fonts.ts 字体装载 + subs.ts 字幕 + Scene.tsx 单组件正片；Canvas2D 纯函数，f210 两次渲染 sha256 全等）
**风格句**：半透明渐变叠面互相穿插出空间 + facetize 三角切面（不裁剪、轮廓锯齿直边、平面溢出轮廓）+ 毕加索式双视角脸（侧脸剪影上画正面杏眼）+ 模版字 destination-out 断口 + 一景四格错位取景。碎面在 8fps 沸腾里「拆开—漂着—重组」，立体主义不是形变而是取景方式的并置。
**技法借鉴** huashu-art-motion（MIT, alchaincyf）references/风格配方/11_cubism.md 与 scripts/engine/scenes/11_cubism.js（265 行）——机制与参数级借鉴，全部以 Remotion(React+TSX)+Canvas2D 惯用法重写（`useCurrentFrame()+1` 纯帧号驱动，几何按 1280×720 重设计），零整段拷贝；文件头注释逐文件登记。

## 锁死项
- **token（types.ts）**：纸 `#d6c8ac`/米白 `#ece3cf`/赭 `#b8975f`/棕 `#6e5538`/深棕 `#3a2c1e`/灰 `#a8a395`/蓝灰 `#8e9eab`/暗灰 `#5a5852`/线墨 `#2e241a`；窗景蓝灰六色 `#c9d3da/#8fa3b3/#e4e6e2/#6f8597/#b4c1cb/#5f7385`；裙 `#6a7a8b`、袖 `#3c4857`（**袖必须比裙深**，否则手臂融进裙切面——配方踩坑原话）、肤 `#e2cfae`、金发 `#c9a256`、唇 `#a8443a`。
- **签名① 透明叠面空间**（plane.ts）：`plane()` 每面一条线性渐变（三色标=混米白/原色/混深棕），α 0.18-0.7；22 手排大面 + 桌下 9 放射扇面 + 70 随机 3/4 边形 + 肌理面（4 点画+4 排线+左缘纸页）+ **9000 布拉克短划砂纹**（55% 米白 α0.28 / 45% 深棕 α0.18）+ **46 条 passage 直线**（1.3px α0.55）。静态层画一次缓存（`staticLayer`，不 reset）。
- **签名② facetize 切面器**（facetize.ts）：平涂进离屏（`{willReadFrequently:true}`）→ getImageData → 抖动三角网（每格随机对角线）→ 质心取色 ×(0.8+0.38rand) + 顶点 0→2 亮暗渐变 → **三角不裁剪画回**（质心 α<120 跳过）——轮廓被切成锯齿直边、部分三角伸出轮廓外。人物主切面 **cell 58（≥58 纪律，34 是 low-poly 不是立体派）**；发区 cell 26 + `only: R>150 && B<130 && R-B>60`（minA 200，且剪影重铺后再切——圆形 clip 会把半张脸切金）；吉他 cell 26。
- **签名③ 毕加索双视角脸**（figure.ts）：侧脸剪影（额-鼻-唇-颌折线）→ 脸部两块肤色明暗重铺面（切面会把金发色带进脸，须还原）→ 前半张脸蓝灰面 `rgba(82,104,128,0.82)` 从脸前缘擦入（**收在 x≈890，后 40% 露肤色与耳**——盖满全脸会让重铺面成死代码）→ 正面杏眼（白杏+瞳+眉弧）→ 红唇楔面 + 螺旋耳 + 白领双三角三扣 + 裙摆腰部 8 条放射切线明暗交替楔面 + 直线外轮廓 `segs()`（每段两端外伸 12px，线画出界）。
- **签名④ 模版字断口**（props.ts）：Fraunces 900 画进离屏 → 12fps 步进（顺序表 CAFÉ/ACFÉ/CAÉF/CFAÉ 轮换，每字 y±9 rot±0.11 hash 相位）→ `destination-out` 每字横杠+竖缝切断口——**断口透出底下叠面，比画纸色条真实**。
- **签名⑤ 一景四格错位取景**（props.ts）：窗景缓存 420×400 大图（55 蓝灰切面+3 斜光束+铁塔+海鸥弧），2×2 四格各给不同基准偏移 `[132,96]/[240,110]/[128,178]/[238,190]` + 相位错动滑动（sin/cos + 8fps hash 微抖）= 同一窗景多视角拼合；每格一片 180px/s 循环滑动的半透明碎面；HERO 段滑动幅度 12→4px 收束定格。
- **签名⑥ 沸腾**：`st=floor(t·8)` 步进——顶点 hash 相位抖 ±8% cell（cell·0.16）+ boilFrac 20-35% 三角明暗跳 ±0.125。CAFÉ 字 12fps、报纸 8fps 微颤（±0.0125rad/±1.5px，折角 sin(20t) 翻）。
- **确定性坑（RECON 点名，工程纪律）**：要 getImageData 的离屏层必须 (a) `getContext('2d',{willReadFrequently:true})`，(b) 每次重画开头 **`g.reset()`（清像素+清 lineJoin/lineCap 状态）而不是 clearRect**——状态残留会让第一帧与之后不一致；**同帧多 pass 场景同样适用**（本工程 figure 层每帧 reset、guitar 层每沸腾步 reset、静态层走 `staticLayer` 画一次不 reset）。Remotion 逐帧重渲天然规避跨帧残留，但层复用+读回的组合必须照此办理。

## 与既有卡的边界
- **vs morph（关键差异声明）**：morph 是平滑 lerp 连续形变（A→B 插值）；facets 是**离散切面**——形体被打散成三角碎片按相位散落/跳变/重组，机制相反。碎片散落是 hash 逐三角平移（非顶点插值），重组是包络收束不是插值形变。
- vs paper-collage：collage 是整片剪纸拼贴（边缘是剪刀折线）；facets 的碎片是切面器的三角网（直边渐变面+不裁剪溢出），且底版是连续叠面空间而非离散纸片。
- vs pop-dot/swiss-print 等几何卡：本卡的几何不是设计语言而是「分析形体的方法」——同一物（脸）必须同时呈现多个视角，这是立体主义专属的取景语义。
- vs swirl-oil（油画笔触）：笔触是连续方向场覆盖；切面是离散网格剖分+质心取色，二者虽同为「油画世界」但渲染机制无关。

## 复用适配点
- 换题只改 `figure.ts` 母题（人物几何+毕加索结构）+ `props.ts` 道具编成 + `script/narration.txt`（帧锚点 A 重标）。
- `facetize()` 是通用「low-poly/宝石切面/数据切面」原语：给 isometric-city/aurora-glass 的 hero 图形可借（传 `only` 谓词做区域细切、传 `scatter` 做「打散-重组」节拍）。
- `plane()` 叠面空间可给一切 1910s 前卫风/海报拼贴当底版语法；`segs()` 端点外伸直线轮廓是立体派速写签名。
- 音频配伍：BGM `12-aurora-glass`（玻璃质感冷氛围对位切面透叠）；SFX 主题音 = 纸/剪切材质族（立体主义=剪与拼），纪律=全部 ≤0.16 gain。
