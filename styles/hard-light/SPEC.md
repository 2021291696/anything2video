# SPEC：霍珀美国现实主义光影叙事（hard-light）

**正本源工程**：`samples-v4/hard-light`（2026-10-07 验证交付）｜**图元库**：工程 `src/style/`（types.ts 双色成对 token + noise.ts 种子随机/值噪声 + room.ts 双版本房间/街景/刷痕 + woman.ts 双版本家具人物/姿态 + light.ts 光斑几何/litClip/墙上人影/浮尘 + extras.ts 旋转柱/拉绳/热气 + subs.ts 字幕 + Scene.tsx 单组件正片；Canvas2D 纯函数，同帧渲两次逐像素一致）
**风格句**：双版本光影裁切 + 硬边光斑缓移扫脸 + 墙上同步投影 + 光带浮尘 + 窗外红砖楼旋转柱 + 竖向拉长 fbm 刷痕。光作为叙事而非装饰：光斑走到哪里，哪里的世界就换成暖色。
**技法借鉴** huashu-art-motion（MIT, alchaincyf）references/风格配方/24_hopper.md 与 scenes/24_hopper.js（150 行）——机制与参数级借鉴，全部以 Remotion(React+TSX)+Canvas2D 惯用法重写（`useCurrentFrame()+1` 纯帧号驱动，几何按 1280×720 重设计），零整段拷贝；文件头注释逐文件登记。

## 锁死项
- **双色成对 token**（本卡纪律，`types.ts`）：背光冷绿族 SH/TS（墙 `#5d8679`/护墙 `#4b6d63`/地 `#5b3d2b`/板缝 `#4a3122`/裙 `#7a2c2a`/发 `#a8893f`/肤 `#c89a84`/木 `#4f3322`）× 受光暖黄族 LT/TL（墙 `#efcf8f`/护墙 `#d8ad68`/地 `#c98b52`/裙 `#cc4a3c`/发 `#f3d67e`/肤 `#f7d3b4`/木 `#a86c3c`）逐物配对 + 砖红 `#b4553a`。**禁第三套中间色**——光色切换只靠裁切换色。
- **签名① litClip 双版本裁切**：`room(g,K)`/`drawWoman`/`furniture` 同一函数两套色各画一张缓存；每帧先铺背光版，再 `litClip([墙WP,地FP])` 裁进受光房间、`litClip([人物光带OP])` 裁进受光家具+人物。
- **签名② 硬边光斑缓移**：单一 dx 主曲线驱动三块光斑整体平移（墙 WP 左缘竖直 (947+dx,167..487)、地 FP 右下展开 (947+dx,487)→(1133+dx,720)、人物光带 OP 左缘 (935+dx,0)→(830+dx,720)）；样片分段 340（画外）→95（钩子入画 0.5s）→58（缓漂）→−45（**光边扫脸**）→−52（收定），扫脸锚点从 tts_build 句表推导（SWEEP_FROM=S03.from+34 / SWEEP_TO=S04.from−1），换文案自动重锚。**光边必须在 60-75% 窗口内扫过主角脸（半脸→全脸）是硬验收**。
- **签名③ 墙上人影**：人物剪影 translate(+100,+12) 画进离屏 → `source-in` 透出背光底版 → 画回光斑区；窗棂竖影/斜影同机制（斜条平行于光斑上沿）。
- **签名④ 光带浮尘 26 颗**：seeded 上漂 7-12s 循环，光带左缘 `bandEdge(dx,y)` 左侧剔除（只在光边右侧显示），lighter 微闪。
- **签名⑤ 窗外对街**：红砖立面 `#b4553a` + 2×4 窗洞半拉绿卷帘高低不一（0.25-0.7）+ 窗洞右侧 10px 硬影；理发店旋转柱红/蓝斜纹 **60px/s 上行（锁死速度）**。
- **签名⑥ 质感**：竖向拉长 fbm `(x·0.06, y·0.006)` 为主 + 斜向辅，1/4 分辨率生成后放大，soft-light α0.2 整幅叠。**横向 fbm 是「水纹大理石」坑，禁用**。
- **签名⑦ 硬边无羽化**：光斑边缘全部多边形 clip，禁 blur/shadowBlur/filter——硬边是本卡的签名。
- **确定性**：全部 seeded（mulberry32 + 格点整数哈希 + 时间维噪声），禁 Math.random/Date/网络；f210 两次渲染 sha256 全等。

## 与既有卡的边界
- **vs neon（霓虹装饰光）**：neon 的光是灯管辉光/装饰语义（发光体本身是主角）；hard-light 的光是日光投影/叙事语义（光斑移动=时间，扫过谁=叙事重音）——光的角色相反。
- **vs aurora-glass（弥散底光）**：aurora 是弥散渐变氛围；hard-light 是硬边块面投影（霍珀油画语言），无羽化、无辉光。
- **vs candle-light（候选池，明暗法）**：candle 走光照图整幅相乘（失边/厚涂/烛光摇曳，柔光）；hard-light 走双版本裁切（硬边/平涂/日光）——2D 用光的两个极端，SPEC 互斥声明。
- vs swiss-print/paper-collage 等平涂卡：本卡平涂但一切形体受「背光/受光」双色支配，且光斑是会动的叙事角色。

## 复用适配点
- 换题只改 `Scene.tsx` 层序里的锚点表（不动）+ `light.ts` 光斑锚点（自动从句表推导）+ `woman.ts` 母题（人物/家具布置）+ `script/narration.txt`。
- `litClip()` + 双版本画法是通用「光在移动」方案：日夜交替/探照灯/窗光扫过/聚光舞台直接复用（把 dx 换成对应驱动量即可）；`wallShadow()` 的 source-in 人影可给任何「投影」语义复用。
- `brushTex()` 竖向 fbm 刷痕可给一切油画/丙烯质感卡复用（参数已在配方踩坑后锁死）。
- 音频配伍：BGM `12-aurora-glass`（冷氛围玻璃质感）；SFX 主题音 = transition 风（光斑入画/扫脸）+ light 微光 + counter 钟表（房间时间感），纪律=克制（全部 ≤0.14 gain）。

## QC 豁免档
- f358-387 定帧 0.97s：浮尘+旋转柱+拉绳+热气+呼吸为合法微动效（probe_liveness SC04 MAD 0.110-0.928 非全静止），不修。
- f1-2 光斑画外全背光：叙事设计（「光还没来」），冷绿房间非黑场（probe_blank 全过）。
- SC02 段 MAD 0.5-0.7 偏低：光斑缓漂是「时间感」本体节奏，非渲染静帧。
- 相机全片缓推 1.00→1.03（f358 钳死）：极缓电影化推入，非抖动。
