# cumulus-light · 新海诚光影（SPEC 登记，战役 v4 批次④ / D5-5）

## 领地

数字光影动画——赛璐珞角色 + 写实室内 + 史诗天光（积雨云/丁达尔光柱/镜头光晕/泛光）。2016 年代《你的名字。》以降的新海诚系数字摄影语言：**光不是氛围而是主角**。

**样片**：《放学后的积雨云》（教室窗边，云比楼高，光柱切进夏天），360f = 12.0s，1280×720@30。

## 技法借鉴登记

技法借鉴 huashu-art-motion（MIT, alchaincyf）`references/风格配方/35_shinkai.md` 与 `scripts/engine/scenes/35_shinkai.js`（197 行）的五签名与光效纪律，全部 Remotion(React+TSX)+Canvas2D 重写（几何按 1280×720 重设计，非等比拷贝），零整段拷贝；文件头注释逐文件登记（src/style/cel.ts / sky.ts / glass.ts / atmos.ts / girl.ts）。

## 签名特征（图元库与参数锁死）

1. **CelShade**（`src/style/cel.ts`）：赛璐珞上色——阴影=clip(P)∩¬(P 平移 (lx·sd, ly·sd))（evenodd 反选），受光亮边=反向平移 rw，按部件顺序「填→影→亮边→描线」遮挡天然正确。参数锁死：sd 大件 22-30（裙 30/上身/后发 26）/脸 10/小件 8；rw 3-9；默认光向 lx=−1 ly=−0.55；线 `#6a4632` 2.2px。附加件：`backlitEdge`（逆光 lighter 暖 rim rgba(255,220,160,.55)）+ 天使环（后脑 8px 亮弧 rgba(255,250,226,.85)）——窗前逆光角色标配。
2. **Cumulus**（`src/style/sky.ts`）：积雨云三步法——①70+12 团蓝灰剪影（线性渐变 `#b7c6e6→#8297c6`）②每团偏向太阳 (+0.22r,−0.3r) 白色径向亮球 0.75r ③整层 blur3.5px + 45% 清晰层。禁「每团径向渐变+受光弧线」（肥皂泡坑）。塔顶须超屋顶线 ≥190px（「云比楼高」视觉句）。呼吸 0.05sin(1.3t)、漂移 7px/s。
3. **Godrays**（`src/style/atmos.ts`）：丁达尔光柱——3 楔形 blur13px 缓存，screen 合成，α (0.75+0.25sin(3.4t))·fadeIn；可加环境宽光轴（α0.16）与英雄光楔（bell 包络，hero 拍全开）；光尘 60 颗 hash2 定相、径向渐变、闪烁。
4. **BloomFlare**（`src/style/atmos.ts`）：镜头光晕（太阳核+10 星芒 0.25rad/s+横丝+5 六边形鬼影沿太阳→画心 α0.04-0.12）+ 泛光（整帧 1/3 缩糊 blur4+brightness1.08 → screen α0.28）。
5. **玻璃水珠**（`src/style/glass.ts`）：只画下缘弧 + α0.28 透明体 + 高光点（实心圆=气泡坑，禁）；一颗英雄水珠带 3px 渐淡水痕滑落（本卡钉在 hero 拍）。

## 差异边界

与 **watercolor-cel**（吉卜力）同为日系但分野清晰：吉卜力=水彩质感+暖光日常（边缘晕染、无硬阴影带、无镜头伪像）；本卡=数字光影+史诗天光（cel 硬阴影带、丁达尔光柱、lens flare/bloom 数字后期、云是体积主体）。与 hard-light（霍珀）同管「光」但语汇相反：hard-light=硬边光斑的静谧孤独（禁 blur），本卡=糊化光柱的璀璨少年感（blur 是语法的一部分）。

## 验收要点（后续复用此卡时）

- 盲测读出「新海诚/夏日天光」为过；光效三红线量化自检全过为过。
- 云禁肥皂泡（剪影+偏移亮球+糊清两层，禁整团径向渐变+受光弧线）。
- 室内 ≥5 层信息密度；水珠禁实心圆。
- 性能：全片实测约 40-70ms/帧（离屏云层+缓存楔形+bloom 小画布），远低于 swirl-oil 50ms 门（本卡非油画族，参考值）。
