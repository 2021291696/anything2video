# SPEC：早期光追 CGI（chrome-ball）

**正本源工程**：`samples-v4/chrome-ball`（2026-10-08 验证交付）｜**图元库**：工程 `src/style/`（types.ts 锁死 token+世界常量 + noise.ts seeded 值噪声 + plastic.ts plastic()/cyl()/taper()/joint()/matte() 着色约定 + world.ts 青绿墙/逐像素透视棋盘/线框→扫描线显影/逐格扫描带 + objects.ts chromeSphere 环境映射/torus/cone/ballPing + cat.ts 猫件（RIG.smooth 体廓+哑光脸） + flare.ts P.lensFlare（核+12 星芒+横丝+5 鬼影） + captions.ts 字幕/片名/RENDERING OSD + Scene.tsx 单组件正片；Canvas2D 纯帧号函数，同帧渲两次逐像素一致）
**风格句**：2D canvas 假装 90 年代光追渲染器——塑料四步着色图元 + 逐像素透视棋盘地面 + 铬球环境映射自转 + 镜像倒影 + 窗日镜头光晕 + 磷光绿线框→扫描线逐行显影开场。认真得有点笨拙的渲染感即情绪本体。
**技法借鉴** huashu-art-motion（MIT, alchaincyf）references/风格配方/15_raytrace.md 与 scenes/15_raytrace.js（300 行）——机制与参数级借鉴（plastic 四步渐变模板/倒影公式/棋盘超采样/flare 排布/线框转场全部照配方锁死值），全部以 Remotion(React+TSX)+Canvas2D 惯用法重写（`useCurrentFrame()+1` 纯帧号驱动，几何按 1280×720 重设计，源配方 1920×1080 常量按 2/3 换算：VP(640,320)/雾 93px/水线 604），零整段拷贝；文件头注释逐文件登记。

## 锁死项
- **token**（`types.ts`）：青绿墙径向三段 `#7dbcb9→#64a6a6→#3f8285`（光源在窗）+ 窗外粉紫天四段 `#a24cc4/#df62ae/#f5a08a/#f8c070` + 棋盘 `#d9dadf/#3e5d62` + 近墙雾 rgb(150,190,192) 35% + 磷光绿线框 `#46ff9a`。禁第三套墙色/天色。
- **签名① plastic() 四段径向渐变塑料着色**（`plastic.ts`，配方四步照搬）：0→白.55 / 0.28→白.06 / 0.62→透明 / 1→深紫 rgba(10,0,30,.42)；反光 lighter 描边宽 0.18R 左偏 0.04R；硬椭圆高光 0.16R×0.09R α.85。肢体 `cyl()` 渐变横跨法向 + 20–75% 白高光线；`taper()/joint()` 锥柱与关节；`matte()` 哑光变体。
- **签名② 逐像素透视棋盘地面**（`world.ts`）：消失点 VP(640,320)，逐像素求交采样 **2×2 超采样**抗锯齿，近墙 **93px 带 35% 雾**（源 140px×2/3）；棋盘 u/v 由地平线透视公式给出（与铬球环境映射共用同一 u 函数）。结果整帧缓存，只画一次。
- **签名③ 铬球环境映射+菲涅尔**（`objects.ts`）：反射向量 R=2(N·V)N−V，向下→棋盘 u（**u 随 t·4.5 平移＝球在转，锁死速度**）、向上→粉紫天四段+一条窗光；菲涅尔边缘随视角增亮；下半球倒像棋盘（近大远小）。
- **签名④ 镜像倒影整体半透明**（`Scene.tsx` mirror()）：各物体按自己接地线 `translate(0,2·gy); scale(1,-1)` 画进**独立离屏层**，整层 α.34 进水线下裁剪区——先画完整层再统一半透明，**禁逐物体各自叠加**（配方 140 颗小球叠成不透明的坑）；水线以下随深度沉入雾色渐隐罩。
- **签名⑤ 镜头光晕 P.lensFlare**（`flare.ts`）：日芯钉在窗内粉紫天 SUN(455,152)——白核（HERO 时 113px ±8% 脉动）+ **12 道星芒 0.25rad/s 长短交替** + **横丝 840px** + **5 个六边形鬼影沿日→画心 0.45–2.0 倍排布**（sin(t·5)·0.03 滑动），全部 lighter 叠加。
- **签名⑥ 绿色线框→扫描线逐行显影转场**（`world.ts` drawReveal）：f1-2 全绿线框（暗底+磷光绿边+墙地网格+四物体轮廓+RENDERING OSD 0%），f3-15 扫描线自上而下逐行显影（亮线 sweepY+上沿 46px 余晖+两道值噪声毛刺，OSD 百分比同步走），f16 完成——「年代媒介显影」转场模板。
- **签名⑦ 短板修正（猫）**：体廓 RIG.smooth 平滑后再着色（禁直柱腿），**脸不做塑料改哑光**（matte，INDEX 原配方"猫腿直柱、脸像面具"两处短板明确修正）；验收=静帧被认成"90 年代 CGI demo"而非"矢量插画"。
- **确定性**：全部 seeded（mulberry32+格点整数哈希+时间维噪声），禁 Math.random/Date/网络。

## 与 studio-oneshot 的边界（RECON §15 撞车标注落 SPEC）
- **studio-oneshot = three.js 真 3D 影棚**：真实几何+光照渲染（瓷质道具/rim 光/Hermite 相机），时代语义当代。
- **chrome-ball = 2D canvas 假装 90 年代渲染器**：塑料感着色约定/逐像素棋盘/线框显影转场全是"模仿当年渲染器"的 2D 技巧，时代语义怀旧。二者"3D 感"需求会被一起想起，但媒介语义相反（假装旧 vs 真做新）——"3D 感"且要年代感选本卡，要真实产品感选 studio。

## 复用适配点
- 换题只改 `Scene.tsx` 层序里的物体布置与锚点 + `cat.ts` 母题 + `script/narration.txt`；plastic/world/flare 三件不随题动。
- `plastic()/cyl()` 是 2D 里出体积的最省套路：aurora-glass/clay-town 的道具、任何"假 3D 图元"直接复用（参数已锁死）。
- 镜像倒影公式（独立层+整体 α+水线裁剪）可给一切"光滑地面"场景复用。
- `drawReveal()` 线框→扫描线是"年代媒介显影"转场模板：CRT 开机/针式打印机/传真机显影换色即可复用。
- 音频配伍：BGM `10-synthwave`（90 年代合成波与时代语义同构）；SFX 主题音 = 数字计算/上电/快门（渲染器人格）。

## QC 豁免档
- f345-377 定帧 1.1s：棋盘 u 平移（球在转含倒影）+光晕脉动+星芒旋+鬼影滑+紫环自转+猫眼 pulse 为合法微动效（probe_liveness SC04 最长连续静止 1 对，非全静止）。
- 帧 0（f1）probe_blank "近乎全屏同色 94%"：线框显影起点设计内暗底（硬切过渡帧豁免，f3 起扫描线即动）。
- SC01 段 MAD 0.65-1.76：微动效本体节奏（呼吸/眨眼/自转），非渲染静帧。
