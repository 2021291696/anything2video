## 1. 定位与领地

- **一句话**：点是内容本身——全屏波点从一个焦点行波呼吸，窗内的无限镜屋灯格扑面飞来，最后红点阵把一切吞掉、也把观众算进无限里。
- **适用**：艺术科普/展览导览/沉浸体验类 promo 与 explainer；任何「图案即主角」的题材。
- **与近亲的边界**：pop-comic 的网点是印刷半调（服务造型），本卡点是**图案本体**；swiss-print 纯平禁纹理，本卡全屏纹理即身份。a2v 此前无波点艺术卡，新领地。

## 3. 六签名（实现位置均在 `src/style/kit.tsx`）

1. **焦点波呼吸单函数** `wave(x,y,t,k,ox,oy)=0.82+0.28·sin(dist·0.012−6t·k)`——全部点层（墙/地/裙/南瓜/桌/窗框/消融）共用；焦点轨 `focalAt(f)` 分段线性移动（少女→南瓜→窗心→屏心）保证跨镜相位连续、点径无跳变。
2. **手绘不规则圆 + 六角网格抖动**：`Dot`=椭圆（asp 0.85–1.15）+随机转角；`hexGrid` ±25%（大点）/±50%（小点）位置抖动、尺寸 ×0.75–1.25。
3. **无限镜屋** `MirrorTunnel`：13×7×3 **规则**格子灯（±0.03 微扰）z 以 `(z0−t·speed) mod 1` 循环飞向镜头，透视 F（窗 100/全屏 170），z∈[0.4,4.0]；远→近排序；小实心核 r=3.2/z+0.6 + **3.2× 径向光晕** `plus-lighter` 叠加；近远两端 fade。**禁**随机散布+大光晕（糊成散景，huashu 实测坑）。
4. **黄南瓜** `Pumpkin`：5 瓣椭圆外→内绘制、瓣间墨描 4px；每瓣 clip 内行排黑点（中列 r=6.3 最大、向两侧×edge 衰减、行向×(1−|row|/6)）；底轴呼吸 `scale(1±0.025·sin(5t), 2−br)`。
5. **滚动点取模纪律** `crawlOff(t,v,sp)=(t·v) % (2·sp·0.87)`——**按真实周期两行取模**；单行取模回绕帧奇偶行错位互换→整片跳（huashu 实测帧差 2.7 倍；离线断言 `research/modulo-assert.txt`：平移 62.64px 点阵逐点相等 PASS / 平移 31.32px FAIL）。裙上白点 sp36 r9 按 32px/s 顺裙爬、clip 裙剪影。
6. **自我消融** `DissolveOverlay`：红覆盖 alpha 渐显（f292-324）+ 全屏 80px 六角点阵从焦点胀满（波前 `obl·1.9−d/850`）→ 饱和（f330-341，capR 40×1.15）→ **收缩 capR 40→15 收在点阵上**（半径封顶、永不为零、不停纯色）；定帧态 `RestField` r=15·wave∈[12.3,16.5] 持续呼吸。

## 4. 短板修正（INDEX：人物与墙同色靠轮廓撑）——默认行为

- `Room` 接 `exclPath`（人物剪影复合路径，`girlSilPath()` 与 `Girl` 共用同一几何）：SVG mask 白底 + **黑填充+黑描边 6px** 的剪影 → 墙/地点阵在人物区内自动去点、轮廓外 3px 隔离带（点阵永不贴到轮廓上）。
- 人物所有部件轮廓 4.5px 墨线（头/裙）/胶囊双层描（臂腿 ink w+4.4）；红裙白点被 clip 在剪影内侧。
- 结尾必须停在图案不在纯色：签名⑥封顶保证；终帧=红底白点阵呼吸。
