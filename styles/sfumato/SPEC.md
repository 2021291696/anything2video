## 锁死项（签名逐条）

- **签名①sfumato 两遍**（配方 v2 返修参数，禁回退）：
  - 静态层：房间画完整层 `blur(1.3px)` 入缓存（烘焙 `paint/static.png`）；
  - 角色层：`blur(1.6px)` 全不透明 → 叠 `α0.82` 清晰层（kit.tsx SceneCanvas 第③步）。
  - **红线：高 blur 低 α 清晰层（blur 2.6px + α0.38）=景深倒置，禁**。
- **签名②油画罩层四件套**（烘焙 `paint/overlay.png`，一次 drawImage）：
  - 暗角径向（0.55 处 α0.3 → 边缘 α0.8）＋黄釉 `rgba(150,110,40,.07)`＋画布经纬（横暗竖亮每 2px）＋油彩笔触肌理 **4000 笔@720p（=9000 笔@1080p 面积等效 4.34 笔/kpx），α0.022–0.028，线宽 3.4–6.7，方向随机**——剂量红线：26000 笔 α0.05 会变梵高，禁超；
  - 龟裂 α0.30（420 条随机游走细裂线@720p，步 4–13px）＋白线错 1px `lighter` α0.12（`brightness(0) invert(1)`，漆皮翘边）。
  - ⚠ 实测坑：罩层在 1920×1080 烘焙再降采样，3px 经纬线出摩尔纹——**罩层必须显示分辨率原生烘焙**（剂量按面积等效换算）。
- **签名③空气透视**：窗洞内三层山 `#9fb4b8 → #8aa1a6 → #7d9294`（越远越蓝越淡）＋湖＋河谷（灰绿→暖赭）＋银白河（宽度随远近 2→10px）＋柏树/圆树＋石桥；fbm 轮廓（seed 3/5/9）。SC04 配「空气透视色签」三段 swatch 可视化。
- **签名④透视地砖真投影**：`y = yh + f·h/Z`（yh=280, f=686, h=5.75；1080p 配方 f=1029×2/3），Z 从 16 往前每块 1.4；地砖双棕 `#a88c64`/`#5c2418`＋soft-light/overlay 双层光池（心 467,633）＋四周压暗。
- **签名⑤扑翼机**（hero 母题）：前缘梁＋6 放射肋＋扇贝后缘膜（quadraticCurveTo 波瓣），远翼 0.78 倍压暗相位错 0.5，扇形尾舵摆动，红衣驾驶者；扇翅 `up=0.5+0.5sin(12t+φ)` 翼尖 −79~+16px；航程 f223-273 x340→500，越飞越远越小（shrink 1→0.82）越淡（α 0.92→0.62）——「远的东西越淡」语义闭环。平面纸飞机认不出，必须肋骨扇形翼。
- **签名⑥光柱＋浮尘**：楔形 blur(28px) 缓存（烘焙 `paint/beam.png`，双层：宽楔 α0.52→0.30＋收窄亮芯 α0.22），每帧 `screen` 叠加 α=0.8±0.3sin(2.3t)（云过日）；浮尘 70 颗沿光柱上浮（相位模型：bx+sin 漂移 / q=((t+ph)%6)/6 / 闪烁 sin(6t+i·1.7)），`lighter` 叠加。
- **INDEX 短板修正（猫）**：体积全靠渐变——橘底三段线性（#e8b878→#d88a3e→#9a5520）＋白胸径向晕入＋背部受光暖边＋虎斑软边弧线＋280 根顺轮廓毛向短线＋轮廓内侧压暗 9px·α0.2（**26px·α0.45 像玻璃罩，禁**）＋半睁杏眼（琥珀虹膜+竖瞳+周期眨眼）。活性：呼吸 ×3（scale 1±0.026 绕后脚轴）/头歪蹭 ±0.16rad+0.05rad 快项/眨眼相位/尾行波 ×2.2/胡须颤。
- **锁死 token**：暗褐墙 `#43321f→#22180e`（fbm 斑驳 seed21）＋地砖双棕 `#a88c64`/`#5c2418`＋远景蓝灰三段＋猫橘 `#d88a3e` 族＋白 `#f4ece0`。

- **版式**：衬线（Noto Serif SC OFL）题签/字幕——羊皮纸片 `#f2e8d0` 底 + 深褐墨 `#3e2410` + 金边 + hash 微转角；标题金调 `#f2e6cc` + 金线。

## 复用适配点

- **两遍 sfumato 配比表**（blur 值/清晰层 α）是一切古典油画感（肖像/文物/博物馆题材）的通用配方：静态层 1.3px / 角色 1.6px+α0.82，可直接抄 `kit.tsx SceneCanvas` 管线。
- `OldMasterFinish` 思路：罩层四件套参数表（暗角/黄釉/经纬间距/肌理笔数×α/龟裂 α+白线错 1px）可打包为一切「古画/老画」题材的后期组件（配方建议名 `<OldMasterFinish>`）。
- 扑翼机「机械鸟」图元（前缘梁+放射肋+扇贝膜）可复用到科技史/飞行器题材。
- 真投影地砖 `proj()`（world.ts）是任何「地面透视」场景的通用件。
- 油彩肌理剂量换算公式：**笔数按画素面积等效（4.34 笔/kpx）换算，α 红线不随分辨率变**。

## 与近邻卡的边界（同族差异声明）

- **sfumato ≠ candle-light（伦勃朗暗调）**：同属油画族——candle-light 是光照图管线（光池表 multiply + impasto 厚涂 + 分离光，暗是主体）；sfumato 是晕涂+罩层的古典日景（光是氛围不是主体，暗角只是收边），**笔触不可见**（肌理是罩层不是造型手段）。
- **sfumato ≠ swirl-oil（梵高流场）**：swirl-oil 笔触即造型（流场长笔三遍分区+深色描边+8fps boil）；sfumato 零可见笔触、零描边、零 boil——「罩出来的旧」vs「画出来的动」。
- **sfumato ≠ light-dabs（印象派）**：light-dabs 短笔触色点分区、笔触位置固定不沸腾；sfumato 无笔触面、靠 blur 两遍+罩层做旧。
- **sfumato ≠ blue-period（毕加索蓝）**：blue-period 宽干笔 cap:butt 可见笔触+单色明度映射；sfumato 全彩古典、笔触消隐。
