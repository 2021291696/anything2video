## 锁死项

- **签名①金箔材质（与哥特金箔同源参数）**：`f = clamp01(0.5 + fbm(x·.004+3)·0.55 + noise(x·.003, y·.08)·0.45·0.5 ± 0.05)`，在金三阶 `[120,78,18]→[196,148,52]→[246,216,128]` 间插值；每 96px 一条 `rgba(90,55,10,.18)` 方块接缝（错缝排布）；墙 = 金箔 × 褐金斑驳 multiply（480×270 fbm 上采样）+ **9000 颗**金粉/暗粉（70% 亮 `rgba(250,226,140,α.3-.8)` / 30% 暗 `rgba(70,40,10,α.2-.5)`）。
- **签名②150 个四类纹样**（seeded 撒布于袍剪影内，`isPointInPath` 拒收脸部/手/头/袖口保护区）：
  - 同心圆三色（30%）：`[红白蓝/蓝金红/紫白金]` 三组，hero 活化后按 `floor(t·1.25)` 离散换色；
  - 深褐底金螺旋（32%）：`#3a2410` 圆底 + `#f2cf6a` 螺旋（5.2π 圈），alive 后 **±3 rad/s** 双向转（`i%2` 定向）；
  - 荷鲁斯眼形纹（22%）：轮流眨 `sin(2.2t+φ)＞0.86` 时闭合（`1-(bl-0.86)/0.07`），上眼睑弧不随开合；
  - 白点簇＋红心（16%）：5 白点环绕 + 红心，alive 后红心按 `sin(6t+φ)` 心跳 ±35%。
  - **纹样合成坑（必守）**：纹样先画满一张 Pattern 画布，再按袍剪影**一次性 `source-in`**（逐个 source-in 会互相清掉）；`source-in` 贴完必须立即恢复 `source-over`（残留 source-in 时后续描边会把整层擦成线——本轮实测事故）。
- **签名③「平面装饰 vs 写实脸」**：袍面 3px 深描边 `#1d140c`、纹样纯平面；脸/手用径向渐变 4 色标（`#fceee2→#f2d2ba→#d9a98c→#b07a5e`，高光偏移 -0.35R）表现体积，`blur(8px)` 腮红/眼窝/唇下影，**仅 1.2px** 淡轮廓。她的闭眼睫向下弯（安眠的眼），花冠五瓣小花 slow rotate。
- **签名④静止帧治理三件套**（全片常开）：34 片金箔碎片翻面飘落（150px/s，方片/圆片 ×3 轮换，`scale(1,cos(5t+i))` 翻面）；420 颗金粉以 26px/s 上浮 + `sin(sp·t+φ)>0.55` 时出四角星（lighter）；花毯 260 朵点头幅度 **0.35**（配方「加幅」参数）。
- **签名⑤goldLeaf 螺旋铺开转场（钩子）**：72px 方块，序 key = `离头距离×0.78 + 方位角×0.12 + 随机×0.08`（原点=她头部 574,244），`q=(p·1.32−key)/0.32`，q<0.5 金箔 1.3→1 落位（带螺旋/眼形/同心圆压纹），0.5-1 金箔褪去露场景；f2 首片（0.03s 钩子纪律）、f26 覆满；暗场段以半强度金粉保非空屏。
- **签名⑥斜向流光**：520px 宽 α.24 亮带，`transform(1,0,−0.45,1)` 斜切，lighter，1.15s **匀速** −200→2300（周期 4.6s），**画在角色之前**（角色自然挡住）；袍内二次扫过走 `source-atop`（只落袍面）。
- **hero 激活波**：R(t) 从相握的手 (622,434) 扩散，f192 起、f285 盖满全袍（=70.4%，60-75% 窗口）；纹样 alive 系数 = `smoothstep((R−dist)/50)`——alive 前装饰「平」（相位冻结），alive 后转/眨/换色/心跳；「激活 n/150」读数角标同源。
- **短板修正（INDEX「桌上的手没接袖子」）**：手与袖接缝处画**袖口环**（黑白格环带 36×13 + 金描边 + 开口椭圆 14×9），手明确从袖口长出来；验收 = 纹样只上身不出界（rejection sampling + source-in 剪影双保险）、脸与袍对比成立（SC03 特写近看脸写实、袍纯平面）。
- **版式**：中文 Noto Serif SC 900 标题（金渐变字）/ Noto Sans SC 700 正文，深褐金边字幕卡（`rgba(22,14,6,.92)` 底 + `#d6a845` 边 + `#f4e6c2` 奶油字）；分离派黑白格饰条；全片暗角常驻。
- **确定性**：mulberry32（**状态在工厂闭包**，禁写进返回函数内——amphora 退化事故的同款坑）/ hash 值噪声 + fbm，全随机表（金粉/碎片/花/纹样/方块/瓦片）模块级一次生成，逐帧代码零随机消费；禁 Math.random/Date/网络。

## 复用适配点

- `gold.ts` 整库拷走即用：金箔材质（goldTex/wall）、粒子三件套（DUST/FRAGS 表 + draw 函数）、drawSweep（comp 参数可换 source-atop 腔内用法）、compositeReveal（goldLeaf 转场，原点/窗口 props 化）。
- `figures.ts` 的「袍剪影 + 一次性 source-in」装配法适用于一切「图案要穿在形体上」的卡（唐装/和服/旗装）；keepout 保护区 + rejection sampling 是「纹样不上脸」的通用解。
- 激活波（alive 系数 = 波前距离 smoothstep）是「静态装饰逐个活过来」的通用编舞件，任何散点元素卡可复用。
- 音频配伍：BGM 配方 `12-aurora-glass`（seed 20261099，drop 9.5=f285）；SFX 主题音 = transition-soft（金箔贴上）+ shimmer/sparkle（金粉/点亮）+ bass-hit（hero 峰值对位）+ chime-crystal（收束），钉帧表同源 `research/beat-sheet.json`。

## 与近邻卡的边界（同族差异声明）

- **gold-robe ≠ gold-leaf（哥特金箔）**：金箔渲染参数同源（f 公式/接缝/三阶 token，属共享材质底层），但风格世界不同——gold-leaf 是中世纪手抄本的「贴金工艺」材质卡（平面装饰、字体/花窗母题），gold-robe 是装饰主义肖像的「穿在人物身上的金」（人物、纹样语义、写实对比、goldLeaf 转场、激活波编舞为独有）。两卡 SPEC 各自声明材质参数出处，互不占领地。
- **gold-robe ≠ swirl-oil / 油画族**：油画族是「笔触方向场」世界（cell/len/boil），gold-robe 是「材质平面 + 图案语义」世界（金箔/纹样/眨眼），零共享图元。
- **gold-robe ≠ dot-infinity（草间）**：同属「图案本体」卡，但草间的点就是内容（全屏波场），克里姆特的纹样是袍面的装饰语义（有剪影、有保护区、有「活过来」叙事）。

## QC 豁免档

- f1 暗场：深褐底 + 半强度金粉微光（probe_blank 27 帧全过佐证非空屏）。
- f370-405 定帧 1.2s：构图冻结但金粉上浮/碎片飘落/花点头/纹样转动眨眼不停（probe_liveness SC07 冻结段相邻 MAD 8.07-8.99 佐证），合法微动非全静止。
- 同心圆「换色」为离散跳变（每 0.8s 轮换一组三色），非连续插值——配方「同心圆三色」语义本体。
- hero 波环在 R>300 后 α 衰减至 0.12 并在定帧段保持可见——激活波的余迹是构图一部分。
- SC04 纹样点名引线允许穿过袍面（rep 纹样取自袍内真实位置）。
- 他的头为「低头侧脸小面」的代码化简化（额/闭眼/鼻/唇/下巴 + 深金发披后），非写实肖像；签名③的写实对比由她的脸承担。
