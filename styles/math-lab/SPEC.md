# SPEC：数学实验室（math-lab）

**入库日期**：2026-10-08（战役 v4.0.0 Wave E·P1，prompt-motion 看片复核立项）｜**正本源工程**：`科普视频/samples-v4/math-lab/`（样片《一只球落的规律》12.53s/376f）｜**图元库**：`src/style/`（choreo.ts + kit.ts + Scene.tsx，无纹理/字体文件依赖，Noto Sans SC 走模板附带 OFL）
**风格句**：数学暗室——近黑深蓝底上发光几何（青/品红/琥珀/紫四色系统），函数曲线实时描绘，左下公式角标随讲点亮、右下 t= 实验时钟贯穿，图形与数值同帧对应；一切内容都是「正在讲的那个函数」。

## 锁死项
- **色 token**（`PAL`）：bg `#050a16`｜cyan `#38e1ff`（球/轴/导引=几何）｜magenta `#ff3d9e`（曲线/速度矢量）｜amber `#ffb54d`（公式高亮/数量）｜violet `#8f6bff`（次级段）｜ink `#dfe9ff`｜dim `#8fb0d8`｜faint `#40628a`——四色分工不混用：几何青、代数品红、结论琥珀、对比紫。
- **公式排版**：衬线斜体 Georgia 变量 + Consolas 数字 + **堆叠分数（横杠真分数）+ 17px 真上标**近似 LaTeX 观感；逐字点亮走 monotone 无过冲（`litAt`），点亮不弹；t² 类结论量转琥珀为唯一高亮语义（借鉴 crt amber 预算纪律：全片 ≤2 处结论性点亮）。
- **t 时码契约**：右下 `t = x.xx s` = 幕内实验时钟，**闭式计走（demoT），回放重置**；物理量全部由 t 闭式驱动（y=½gt²、v=gt），缓动只许用于非物理量（网格亮起/相机/柱升 = hermite1 端点零斜率；点亮 = monotone）。
- **辉光系统**：shadowBlur 分层晕、白芯 `#f4faff` 不糊；全片呼吸 sin 0.75Hz ±4%（网格）~±12%（曲线/冻结段）；坐标网格恒弱辉光（alpha 0.10 + blur 4）不与主体争焦点。
- **一图一概念**：一幕一个测量层；幕间硬切=实验重放（时钟重置）；上一幕道具主动退场（SC04 球板左滑）。
- **随机**：零随机源——全闭式数学 + sin 呼吸（禁 Math.random/Date/网络，同帧渲两次逐像素一致）。

## 词汇清单
`drawBackdrop`（暗底+网格弱辉光+暗角+底部信息带）｜`drawBall`（白芯青环球+彗尾：历史位置闭式倒推，速度越快尾越长）｜`drawReleaseRing`（释放环 10f）｜`drawVelocityArrow`（品红速度矢量，长度∝v）｜`drawRuler`（量具线+已量段着色+秒刻度）｜`drawAxes`（draw-on 坐标轴+秒刻度）｜`drawCurve`（发光曲线 0→t 实时描线，90 段闭式采样）｜`drawGuides`（球↔曲线点↔轴刻度三重虚线导引=联动签名）｜`drawEnergyDot`（能量点沿曲线巡行+双尾迹，兼定帧微动效）｜`drawColumns`（×k² 数量柱，柱顶=曲线点）｜`drawBracket`（「y ∝ t²」括式）｜`drawFormula`（公式角标面板：逐字点亮+堆叠分数+真上标+读出行）｜`drawTimecode`（t= 实验时钟面板）｜`drawHud`（品牌+幕概念标签+右上角标）｜`drawSubs`。
**共享数学层**：`common/motion/hermite1`（非物理量缓动，端点零斜率）+ `monotone`（点亮轨无过冲）——直接 import template 共享层。

## 复用适配点
1. **任意「函数演示」题材**：换 choreo.ts 的物理闭式函数（单摆 θ(t)、指数增长、三角函数…）与句锚即可，图元库全部复用；三重联动导引（球↔曲线点↔公式量）是通用联动件。
2. **实验重放叙事口径**：一幕一概念，每幕同一实验换测量层重放，时钟重置——同风格沿用此叙事口径（非严格等分切拍）。
3. **crt-terminal 边界（差异声明）**：crt 是终端字符流美学（一切内容是打出来的字符、等宽字+扫描线+曲率）；本卡是**数学图形语言**（发光几何/坐标系/矢量是主角，字符只作 HUD 数值注记），无扫描线/曲率/打字机隐喻。本卡为 huashu 语法层 t1_3b1b 的视觉底座（叙事语法留语法层立项，本卡只做视觉卡）。

## QC 豁免档
- 定帧段（0.8-1.2s）：曲线辉光呼吸+巡行能量点+括式微呼吸为设计内微动效（liveness MAD>0.15），非死动画。
- 释放前球静止为物理事实（自静止），网格亮起/释放环提供同窗运动。
- 暗底均值亮度低为风格本体（blank 判据按帧定性：min/max 光谱正常非黑屏）。
