# SPEC：国风长卷·敦煌月窗（guofeng-scroll）

**正本源工程**：`科普视频/samples-d8/s34-guofeng`（2026-10-06 验证交付）｜**图元库**：`src/style/kit.tsx`（纯代码 SVG/CSS，无纹理依赖）
**风格句**：暖黑底 + 圆形月窗展示平涂壁画内容 + 竖排题跋字幕 + 朱印 + 长卷横移 + 唯一虹彩渐变点缀。

## 锁死项

- **色 token**（`GF`）：bg0 `#0a0806`｜bg1 `#1c130a`｜gold `#c9a227`｜goldBright `#e8c56a`｜goldDim `#8a6f2a`｜石青 `#3a6b8c`｜石绿 `#5b8c6e`｜土红 `#9c5333`｜米白 `#e8dcc0`｜**朱 `#c03428`（全片唯一高饱和红，只给印章，一片 ≤2 次）**｜剪影墨 `#221a12`。
- **月窗**：`MOON` 常量圆心 (640,352) 半径 218 **全片恒定**；`MoonWindow` 描金双环（外环 5px goldDim + 内环 1.6px gold，自顶部顺时针描出）；窗内内容可变（构图纪律：窗位不变、内容变）。hero 段月窗可收进卷轴，但须描回原位收卷。
- **题跋**：`Inscription` 右起竖排、Noto Serif SC、逐字淡入（stagger 5f、单字 13f），**每列 ≤8 字**；落款信息用横排 14px 米白 52% 小字置于 y660（限出处类辅助信息）。
- **朱印**：`Seal` 方形 64px、内嵌米白双框、竖排 ≤2 字、落印 scale 1.55→1（8f 快落）+ 印泥晕一圈。
- **长卷**：`ScrollContent` 土红卷底 + 上下描金卷轴杆 + 内容右→左单向卷动；`ScrollProgress` 底部 9 点朱暗阶（#a53a30，小面积导航件）随卷同步点亮。
- **虹彩**：`IRIDESCENT_STOPS` 五色渐变（#7ee8d0→#c9e86a→#e8c56a→#e88aa0→#8aa8e8）**全片只给唯一主角**（`IridescentShrine` 沿形 stroke + seeded 微粒子），其余元素全部平涂壁画色系。
- **笔触**：佛龛/山形/人物全部几何化（拱顶 path + 圆头三角佛 + 折线山 + 剪影杖行），不做细节堆砌。
- **节奏**：允许并要求一段 2s 级纯画面呼吸（微尘/微闪全冻结的完全静止 ≥0.8s + 仅微动效段）；结尾定帧微动效 0.8-1.2s。

## 复用适配点

- 无 staticFile 纹理依赖，`kit.tsx` 整库拷入 `styles/<sku>/` 即用；镜头组件演示了月窗四态（开窗/题跋/纹样渐变/收卷定帧）与长卷 hero 的完整衔接。
- 题跋文案换主题时保持「一句碑文原文 + 一句定性」的双列结构；朱印文字取主题关键词 2 字。
- BGM 走 `bgm_generate --style guofeng-scroll`（15-guochao 配方）；落印音效复用 mgaudio `sfx.stamp('seal')`。

## QC 豁免档

- **呼吸段静止误报**：f346-369 完全静止 + 微动效尾段会被 frame_metrics 判「画面不动」——本卡签名特征 5，属合法静止，看帧定性不修。
- **朱暗阶进度点**：ScrollProgress 用 #a53a30（同族低明度小面积），不触发「第二高饱和红块」判罚；若评审口径从严，可改米白点+朱点混合。
- **暖黑底大面积暗部**：底色 #0a0806 会拉低整帧亮度指标——月窗内容区亮度为准，不修底色。
