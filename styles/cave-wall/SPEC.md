# SPEC：洞穴岩画（cave-wall）

**正本源工程**：`samples-v4/cave-wall`（2026-10-07 验证交付）｜**图元库**：工程 `src/style/`（noise.ts 种子随机/值噪声 + relief.ts 浮雕岩壁/岩面贴图 + charcoal.ts 炭笔体系/喷雾 + handprint.ts 负形手印 + embers.ts 火光/余烬 + actors.ts 画者/野牛群 + title.ts 题字/字幕 + Scene.tsx 单组件正片；Canvas2D 纯函数，同帧渲两次逐像素一致）
**风格句**：噪声浮雕岩壁 + 「颜料吃进岩石」的炭笔图形 + 拉斯科式两姿态动物 + 负形手印 + overlay 火光摇曳/金色余烬 + 图案平移式炭笔沸腾。远古媒介世界：画在什么上（岩壁），不是画了什么。
**技法借鉴** huashu-art-motion（MIT, alchaincyf）references/风格配方/01_cave.md 与 scenes/01_cave.js（364 行）——机制与参数级借鉴，全部以 Remotion(React+TSX)+Canvas2D 惯用法重写（`useCurrentFrame()+1` 纯帧号驱动），零整段拷贝；文件头注释逐文件登记。

## 锁死项
- **色 token**（`PAL`）：墙三赭石 `#ce925a`（亮）/`#6e4426`（暗）/`#b6643a`（红斑）｜炭黑 `#21150d`｜红赭 `#9c3520`（+暗 `#74261a`）｜黄赭 `#c9772f`｜白垩 `#f0dfbf`｜野牛 `#8c3d22`/头 `#76301a`｜题字红 `#9b2a18`。全低饱和大地色，禁入霓虹/高饱和色相。
- **签名① 噪声浮雕岩壁**（`relief.ts`）：半分辨率高度场 `fbm(x·0.0022,4oct)·1.0 + fbm(x·0.011,3oct)·0.16 + noise(x·0.05)·0.03`，有限差分法线 ×52，光源 `L=(-0.55,-0.62,0.56)`，`shade=clamp(0.5+(dot-0.56)·0.9)`，底色三赭石两层低频 fbm 混合 ×(0.72+shade·0.55)，两层颗粒 + 随机游走裂缝（+1.6px 亮垫线）+ 暗角 + 静态暖光。**中频系数 >0.2 会变迷彩——锁 0.16**（配方踩坑量化）。
- **签名② 颜料吃进岩石**（`charcoal.ts`）：统一画法 `shape()`——fuzz 图案（稀疏炭点，宽 2lw+7）→ ink 图案（炭黑 + 7% 孔洞 + 噪声>0.58 大孔，宽 2lw）→ 不透明平涂盖内半圈；整个颜料层画完后**一次** `source-atop` 叠 `figTex()`（岩面阴影压暗/亮处提暖 + 颗粒 + 低频干湿斑）。填色禁 multiply（白垩会被吃掉）。
- **签名⑥ 炭笔沸腾**（`charcoal.ts`）：两张 256² 图案每 1/9s `pattern.setTransform` 随机平移（`boilSeed(f)=floor((f-1)·9/30)`）——几何不动、颗粒在跳，比抖动路径省且不变形。
- **签名③ 两姿态交替奔跑**（`actors.ts`）：`ph=floor((f+phase·7)/7)%2` 每 7 帧换腿（伸展/收拢两套腿端点）+ 整体颠簸 x±3/y∓7 + 头绕颈点 ±0.12rad；牛群三个体相位 0/0.5/0.25 反相；腿只用炭线、身体填色剪影 + 背脊 22px 深色晕染（拉斯科式明暗）。拉斯科式体型：巨大肩峰 + 下垂的头 + 颏须 + 低臀。
- **签名④ 负形手印**（`handprint.ts`）：320² 临时层两层高斯喷点（σ46·3200 + σ28·1400）→ `destination-out` 手形蒙版 → α0.3 补色。**手形必须逐块 fill**（手掌/手指/腕各自 Path2D，子路径绕向相反 nonzero 会抵消出缺口）。活手印：f207-239 正形手伸向岩壁 → f240 拍上（sprayBurst）化为负印（grow 0.55→1）——正负形转换是样片的签名叙事时刻。
- **签名⑤ 火光 overlay + 余烬**（`embers.ts`）：火光径向渐变**必须 overlay 合成**（禁 lighter——lighter 洗白暖色、赭石失饱和）；强度 `0.14+0.11·noise(9.5t)+0.04·sin23t+0.03·sin37t`、中心游移 ±60/±36、暗角反向呼吸；余烬 49 颗三组（亮核 r2.6-5.4 + 3.6 倍光晕 + |sin| 闪烁 + sin(qπ) 首尾淡入淡出，lighter）；手印各自独立相位呼吸暖光。
- **短板修正（INDEX：人形太卡通）**：画者轮廓降采样到 **14 点**（12-16 区间）+ 静态大手绘抖动 ±5px（seed 固定，几何不沸腾）+ 红赭平涂 + 炭描边 + 一道炭痕眼。验收=静帧里人形与野牛同等「原始」（out/stills/frame-60.png 对照通过）。
- **确定性**：全部 seeded（mulberry32 + 格点整数哈希 + 时间维平滑噪声），禁 Math.random/Date/网络；f210 两次渲染 sha256 全等。

## 与既有卡的边界
- **vs sand（灯箱沙画）**：sand=深沙底擦出亮形体（减色媒介）；cave=赭石岩壁炭绘+矿物颜料（加色媒介）——媒介语义相反。
- **vs chalk（黑板粉笔）**：chalk=深绿板白垩线（版式卡）；cave=浮雕岩面+颜料体积+火光照明（整幅媒介世界）。
- vs 其余 v4 新卡（tomb-wall 埃及墓室/因科唐线体系）：cave 管旧石器 Europe 岩壁世界，tomb-wall 管埃及灰泥墙程式世界（色板/字形/光影体系全不同）。

## 复用适配点
- 换题只改 `Scene.tsx` 相机 Hermite 站表 + `actors.ts` 母题布置（世界坐标表）+ `title.ts` 题字文本。
- `relief.ts` 是通用「刻在硬表面」渲染器：换三个底色 token 即得石刻/木刻/浮雕徽章底版；`figTex()` 可给任何颜料层复用。
- `charcoal.ts` 的 pattern 沸腾法可移植给 chalk/sand 类手绘卡（不变形、便宜）；`stencil()` 负形喷绘可独立用于「按手印」类互动叙事。
- 音频配伍：BGM `06-collage`；SFX 主题音 = transition 风（火把/气流）+ fluid sand（颜料喷雾）+ impact 石族（拍壁/苏醒）。

## QC 豁免档
- f362-397 定帧 1.2s：火光摇曳 + 余烬 + 两姿态 + 炭笔沸腾为合法微动效（probe_liveness SC04 采样对 MAD 2.7-3.9，非全静止），不修。
- f1-2 暗场：场亮系数 0.16 设计内（暗壁+火光可见，probe_blank 20 帧全过无豁免）。
- 炭笔 9fps 图案平移造成整幅微闪：沸腾是风格本体（签名⑥），帧差探针记「整帧微动」属预期。
- 相机站间缓移（0.82-1.44 变焦）：火把沿岩壁走的叙事运镜，非稳定问题。
